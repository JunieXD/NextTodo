# 界面

视觉和交互的规格。定规格时用的可点击原型在正式前端做出来以后删掉了，要看可以在提交 `57a07ad` 里找。

## 设计方向

- **一处大胆，其余克制**：文件夹列表左侧的“轨道”是唯一的视觉重点，其他地方保持安静。
- **颜色有含义**：主色翡翠绿只表示“可做”；等待中用中性灰和虚线；逾期红，今天到期琥珀色。不用颜色做装饰。
- **Material 3 的配色和组件，iOS 的结构和手势**：Material 3 的颜色角色、导航指示条、筛选标签、悬浮按钮、对话框；iOS 的大标题、圆角分组列表、可拖动的底部面板、滑动操作。
- **动效只回应操作**：只在用户操作后出现，用来说明发生了什么变化；没有自动播放的装饰动画。

## 圆角、间距、阴影

- 圆角按层级区分：底部面板和对话框 28，快速添加栏 25（胶囊），其中的输入区 20，悬浮按钮 16，分组列表和关系图节点 14，分段控件 10（选中项 8），筛选标签和文件夹图标 8，描述里的清单框 5，事项勾选框为圆形。
- 分组列表左右边距 16，分组标题缩进 32。普通行最小高 56，轨道列表行高固定 64。
- 分隔线 0.5px，从文字起点开始，不贯穿图标。
- 左栏各项之间留 2 的间隙，选中项和悬停的相邻项不粘在一起。
- 阴影只用两级：分段控件选中项用一级，浮在内容上的元素（快速添加栏、悬浮按钮、提示条）用三级。

## 布局

| | 手机（窄于 1000px） | 电脑（1000px 及以上） |
|---|---|---|
| 结构 | 顶部栏 + 内容 + 底部栏 | 左栏 272 + 中栏 + 详情栏 400 |
| 导航 | 底部栏三项：接下来、文件夹、设置（图标是头像） | 左栏：接下来、已完成、“文件夹”下的文件夹树、搜索；设置在左栏左下角（头像和名字），在中栏打开 |
| 收起 | | 中栏顶部左侧的按钮收起或展开左栏，带过渡 |
| 详情 | 底部面板 | 详情栏：默认收起，点事项时滑出，再点同一项或关闭按钮收回；详情开着时点别的事项直接换内容，不播动画 |
| 快速添加 | 浮在底部栏上方 | 中栏标题下方 |

- 手机顶部栏高 56（加安全区），滚动前透明，向下滚过大标题后显示毛玻璃背景、分隔线和居中的小标题。
- 进入文件夹、从“接下来”进入“已完成”、进入[设置](#设置)的子页时，新页面从右侧滑入，返回时反向。电脑上换到左栏的另一处，或在列表和关系图之间切换时，中栏淡入（0.2 秒）。
- 文件夹树的顶层是根目录（图标与文件夹区分），展开是顶层的文件夹；计数是直接放在里面的待办数。不能新建和根目录同级的文件夹。
- 手机“接下来”页的大标题右侧有“已完成”按钮（历史图标）。

### 返回

Android 的返回键（含侧滑返回）一次退一步：

1. 先关掉最后打开的东西：对话框、弹窗、展开的 AI 整理编辑页、文件夹菜单、关系图的连线状态、事项详情。
2. 都关了以后，在文件夹里回到上一级，在“已完成”回到“接下来”，在设置的子页回到设置首页。
3. 在底部栏的页面（“接下来”“文件夹”“设置”）之间切换不算一步，再按返回就退到后台。

网页的返回按地址的历史记录走，打开详情会加一条记录，所以返回也会先关掉详情。

### 设置

设置是一个页面：手机上是底部栏的第三页，电脑上点左栏左下角的头像，在中栏打开（详情栏收起），内容最宽 600。首页按类别分组列出，点一类进入它的子页；地址是 `/settings` 和 `/settings/<类别>`，别处要打开某一类（比如还没配置模型时点 ✦）直接进那一页。

| 类别 | 内容 | 首页右侧 |
|---|---|---|
| 账号（最上面的卡片：头像、显示名、用户名） | 显示名、修改密码、已登录的设备、退出登录 | |
| 本机模式（本机模式下代替账号，见[本机模式](local.md#界面)） | 说明、备份、恢复、改用服务器 | |
| 外观 | 主题（跟随系统、浅色、深色） | 主题 |
| 提醒和后台（Android、桌面 App） | Android：通知、准时提醒、自启动和省电；桌面：登录时启动 | |
| AI 整理 | [模型配置](ai.md#模型配置) | 模型和保存位置 |
| agent 接入 | 令牌；桌面 App 还有命令行 | |
| 邀请注册（管理员） | 邀请码、生成邀请码 | |
| 关于 | 版本和更新、使用教程 | 有新版本时写“有新版本”，管理员的服务器能升级时写“服务器可升级” |

- 首页分五组：账号（或本机模式）；外观、提醒和后台；AI 整理、agent 接入；邀请注册；关于。
- 子页从右侧滑入，返回时反向，同进入文件夹；电脑上标题上方的“设置”回到首页。修改密码、生成令牌和令牌生成后的接入写法是弹窗。AI 整理的配置保存或清除后，回到打开它之前的页面。
- 打开事项（点提醒、小组件里的事项）或快速添加时，在设置页的先回到“接下来”。

## 组件

### 事项行

- 勾选圆圈：可做是主色实线圈；等待中是轨道色虚线圈；已完成是主色实心并带对勾。触摸区域向外扩到 44。
- 标题单行，超出省略。下面一行次要信息依次是：文件夹路径（只在“接下来”和搜索结果里显示）、“今天已完成”（今天完成过的重复事项，主色）、截止时间（重复的事项用循环图标代替时钟）、“等 N 项”、“解锁 N 项”（做完它马上能开始的后续数，为 0 不显示）。
- 等待中的标题用次要文字色；已完成的划掉。

### 轨道

文件夹列表按依赖顺序排列，左侧画类似 git 提交图的轨道：

- 勾选圆圈就是轨道上的节点；依赖沿轨道从前置所在行连到后续所在行，并行的支线分开成几列，列宽 24。
- 像地铁线路图那样合并线路：一个事项有几个后续时，共用一条轨道，到各个后续处分出去；几个只有这一个后续的事项指向同一项时，汇成一条轨道再接进去。常见的“一对多”“多对一”只占两列。合并有时会让分出去的线横穿别的轨道：两种合并都做、只做一种、都不做，四种排法里取交叉最少的，一样时取列数最少的。
- 合并后仍超过上限（手机 3 列、电脑 5 列）时，这个文件夹的列表不画连线，勾选圆圈排成一列，顶上一行“依赖较多，列表里不画连线”，点它切到关系图。
- 只画文件夹内、未完成事项之间的依赖，冗余的依赖不画（同关系图）。
- 从可做事项出发的线用主色（65% 不透明），其余用轨道色。
- 文字起点随轨道列数后移，分隔线跟着对齐。

### 关系图

- 布局：正式版用 ELK Layered，在实现时用真实数据对比几组参数调到最好。要求：连线不穿过节点，交叉尽量少，链条尽量直，可做的事项排在第一层。手机从上到下排，电脑从左到右排。
- 节点：可做用 primary-container 填充；等待中是白底描边，带“等 N 项”；已完成灰底划掉；文件夹外的事项虚线框、半透明，上方标注所在文件夹。手机节点宽 104–146（按屏幕宽度自适应），电脑 184，高 60。
- 选中节点外加主色描边；不在它前后链上的节点降到 28% 不透明，链上的连线变主色并加粗。
- 画布背景是随平移和缩放移动的网点。
- 手势：单指或鼠标拖动平移；双指捏合缩放（以两指中点为中心，同时可以平移）；触控板双指滑动平移，捏合或 Ctrl + 滚轮缩放。缩放范围 0.35–2.5。拖动之后不触发点击。
- 连线：点“连线”后依次点前置和后续，顶部提示当前步骤，前置节点会有脉冲光圈。连出循环时拒绝，并列出环上的事项。
- 点连线弹出删除确认。

### 底部面板（手机详情）

- 两档：半开（屏幕高的 60%）和全开。半开时不遮暗背景，可以继续点后面的列表或节点，详情跟着切换；全开时背景变暗。
- 从任何位置都能拖：内容滚到顶以后继续下拉，就是拖动面板；半开时上推会先展开到全开。快速下甩：全开降到半开，半开直接关闭。
- 半开时内容也能完整滚到底。
- 拖到关闭时，面板从松手的位置继续滑下去。

### 弹窗、对话框、提示条

- 弹窗（选文件夹、选前置后续、修改密码、生成令牌）：手机上是底部面板，电脑上是居中的 440 宽卡片。打开时播放一次动画，之后界面刷新不再重播。
- 选前置后续：和文件夹页一样分层，从事项所在的文件夹开始，先列子文件夹（只列里面有可选事项的，注明几项），再列这个文件夹里的事项；顶上一行回到上一级。换一层时搜索框不动，面板不动，下面的内容左右切换（进入子文件夹从右侧进，回到上一级从左侧进），从顶上开始显示；开始和清空搜索时也从顶上开始。已完成的、已经连上的不列出，连上会成环的列出但不能选。搜索时在所有文件夹里找标题和详情，结果注明所在文件夹。
- 截止时间弹窗：上面是月历，下面一组设置行（样式同设置页的行）：
  - 月历：一周从周一开始，顶上是“2026年11月”和换月的 ‹ ›；固定 6 行，前后月份的日期颜色淡一些，也能点。今天用主色文字，选中的日期是主色实心圆。用键盘时方向键换日期。
  - 时间：右边是“18:00”或“不设时间”（截止到当天结束），点开是[时间选择](#其他)。
  - 提醒：设了时间才能选，否则写“设置时间后才能提醒”。
  - 重复：不重复、每天、每个工作日、每周、每月和自定义；已完成的事项不能设，写“已完成的事项不能重复”。选自定义多出“间隔”一行：数字加减（1–365）和“天、周、个月”的分段控件。按周重复时（每周，或自定义的单位是周）多一行“周几”：一到日七个圆形开关，可多选，默认是截止日期那天，最后一个不能关掉；选了周几，菜单就显示成选的日子，如“每个工作日”“每周一、三、五”“每 2 周的周二、四”；再选别的项（如“每周”“自定义”）就回到不选周几。设了重复再多一行“下一次从”：“截止日期算”或“完成那天算”。重复写出来是“每个工作日”“每周一、三、五”“每 2 周的周二、四”这样；没动过周几的是普通的每周，写成“每周”，跟着截止日期在周几。
  - 详情里截止时间一行写成“11 月 10 日 18:00 · 每周”。
- 详情里重复的事项在截止时间（和提醒）下面多一行“已完成”：“共 12 次，上次是昨天”，最近一次是今天的写“共 12 次，今天已完成”，还没完成过的写“还没有完成过”（灰色）；结束重复以后仍然显示。底部“删除事项”上面多一行主色文字的“结束重复并完成”。
- 弹窗底部的按钮一样高（40，胶囊形），靠右排：主操作是实心按钮，其他操作是浅色底的色调按钮，“取消”是文字按钮；删除、清除这类单独放在最左边，用红色文字，和其他按钮隔开。
- 对话框：Material 3 样式，用于确认会丢失或改变状态的操作（删除依赖、前置没完成时标为完成）。
- 提示条：反色背景，带一个操作（多数是“撤销”），5 秒后消失。

### 其他

- 控件都是自己做的，各端一样，不用浏览器自带的下拉框、日期时间框、复选框、校验气泡和悬停提示；只有选文件（恢复备份）用系统的窗口。
- 分段控件（iOS 样式）：列表和关系图切换、描述的预览和编辑切换、外观选择，以及只有两三个选项的设置（思考程度、重复的单位和下一次从哪天算）。
- 下拉选择：选项多的用它（提醒、重复、AI 服务商）。点开是和“…”菜单同样的列表，当前项右边打勾；在设置行上靠右对齐，在输入框样式的格子上靠左对齐。
- 时间选择：时和分两列，分钟每 5 分钟一档，原来的时间不在档上时也列出；点开时两列滚到选中的位置。点小时后再点分钟，点了分钟就收起；没设时间时要先点小时。底部是“不设时间”。
- 数字加减：两边是 − 和 +，到了上下限的那边不可点；中间的数字也能直接输入，超出范围的按上下限算。
- 输入建议：输入框下方弹出候选（如 AI 设置里从接口获取的模型），聚焦时列出全部，输入后按包含的文字筛选；可以用方向键和回车选。
- 复选框：圆角方框，和描述里的清单一样（如整理建议里勾选要采纳的修改）。
- 表单校验：提交时第一个空着的必填项边框变红，表单下方用红字写“请填写××”；服务端的校验错误同样标在对应的项上。
- 悬停提示：只有图标的按钮，用鼠标悬停约半秒后在旁边显示说明，反色小气泡（和提示条同色）；手指点按不显示。说明就是按钮的无障碍名称。
- 筛选标签（Material 3 样式）：显示已完成、包含子文件夹。
- 快速添加栏：左边是有底色的输入区（和搜索框同色），右边依次是 ✦（切换 AI 整理）、目标文件夹（只在“接下来”里，默认根目录，名字过长时省略）和发送按钮；发送按钮两种模式都有，没有内容时不可用，切换模式时右边的按钮不移动。输入区随内容增高，最多 5 行，再多就在框内滚动；变高时按钮留在底部。占位文字只占一行，放不下时省略。回车添加事项，标题不能换行，粘贴的多行文字合成一行。“接下来”和每个文件夹各有一份草稿：没提交的文字在切换页面、关掉再打开后仍在，提交后清空，退出登录时删除。
- 快速添加栏的 ✦ 按钮切到 [AI 整理](ai.md#添加)：✦ 按钮变为实心，回车换行，用发送按钮提交，电脑上也可以按 Ctrl + Enter（macOS 上 ⌘ + Enter）。设备记住上次用的模式；还没配置模型时，点 ✦ 打开设置里的“AI 整理”。
- 展开编辑：AI 整理的内容超过 3 行时，快速添加栏右上方出现展开按钮。手机上打开全屏的编辑页，电脑上打开居中的大窗口：标题“AI 整理”，右上角是收起按钮，下面是填满空间的输入区，右下角是目标文件夹（只在“接下来”里）和发送按钮。编辑页和快速添加栏是同一份草稿，收起后文字留在栏里；发送后关闭编辑页。按键规则和栏里一样。
- AI 整理请求行：在所在文件夹的事项列表顶部，“接下来”顶部单独一组“AI 整理”（带文件夹路径）。左侧是状态图标（等待 ✦ 灰色、整理中转圈、失败为红色感叹号），标题是原文第一行，下面一行是状态，失败时是红色的原因，右侧有“重试”。点开是原文和状态，失败的可以改原文后重试或按原文添加；右键菜单有重试、按原文添加、删除。
- 设置首页的“AI 整理”一行显示所用模型和保存位置，点开是模型配置。
- 描述里的清单是圆角方框，和事项的圆形勾选框区分开；可以直接点选。
- 图标：24 网格、1.8 线宽、圆头圆角的线性图标。正式版用 Lucide，缺的自己按同样规格画。

## 产品图标

- 图形是一段清单：左边一条轨道串起三项，从上到下是已完成（实心圆点，对勾镂空）、可做（圆环）、等待中（虚线圆环），右边各有一条标题，画法和 App 里的事项状态一致。
- 底板是圆角方块，从左上 `#2E8E6C` 渐变到右下 `#14563F`。图形是白色；轨道、等待中的圆环和它的标题用 `#A6F2D1`；已完成的标题是半透明的白色。
- 单色的场合（macOS 菜单栏的模板图，Android 的通知小图标和主题图标）整个图形只用一种颜色，浅色部分降低不透明度。
- 图标文件都由 `apps/web/scripts/icons.js` 生成：网页的 `icon.svg`（也是浏览器标签页图标和左栏、登录页的品牌标）和各尺寸 PNG，Android 自适应图标的背景、前景、单色三层和通知小图标，macOS 的 `icon.icns`、各尺寸 PNG 和菜单栏图标，Windows 的 `icon.ico`（也是托盘图标）。改图形只改这个脚本，然后在 `apps/web` 下运行 `node scripts/icons.js`；脚本要用 `rsvg-convert`（librsvg）和 macOS 自带的 `iconutil`。

## 交互细节

- 完成一项：勾选框弹一下；这一项在原位多停留 0.9 秒，再用 0.3 秒收起，下面的行随之上移；收起期间轨道淡出，排好后按新的连线淡入；它解锁的事项闪一下 primary-container 底色（1.6 秒），提示条写“解锁了‘××’”，并附“撤销”。恢复成待办时提示条写“已恢复‘××’”，同样附“撤销”。重复的事项勾选框同样弹一下，但不划掉、不收起，截止时间随即换成下一次（“接下来”里这一行随之移到新的位置）；前面出现“今天已完成”；提示条写“下一次：××”，附“撤销”。结束重复并完成和普通的完成一样划掉、收起。
- 前置未完成时勾选：先弹对话框确认。
- 列表行右滑超过 90px 完成，左滑超过 90px 删除，删除后可撤销。
- 文件夹里的事项和子文件夹可以拖动排序：手机上长按（约半秒）拿起一行，电脑上用鼠标按住直接拖，其他行让位。各行一样高，文件夹名过长时只显示一行、末尾省略。事项拖出依赖允许的范围时弹回，并提示是哪一项挡住了；子文件夹的顺序不受限制，左栏按同样的顺序显示。“接下来”按截止时间分组，不能拖。
- 右键菜单（电脑上用鼠标时，Mac 上按住 Control 点按也算右键；手指或触控笔的长按留给拖动，带触屏的电脑也一样）：事项有“打开”“标为完成”或“重新打开”“移动到…”“删除”，重复的事项在“标为完成”后面多一项“结束重复并完成”；文件夹（左栏和文件夹列表里）和它的“…”菜单相同，即“新建子文件夹”“AI 整理事项”“重命名”“移动到…”“删除文件夹”（需确认），根目录只有“新建文件夹”和“AI 整理事项”。其他地方右键没有菜单；输入框、选中的文字和链接保留浏览器自己的菜单，用来复制粘贴。

## 文案

- 简明书面：用“暂无、无法、失败、已、将、须”这类书面说法，句子尽量短；不用“没能、不对、马上、好了”这类口语，不对用户称“你”。界面、提示、错误信息、小组件、通知、命令行和工具输出都按这个风格。
- 用用户能懂的话，不用系统内部的叫法；同一个操作从按钮到提示用同一个词（“撤销”→“已撤销”）。
- 空状态说明下一步能做什么，比如“暂无事项。可在下方输入，或让 agent 拆分计划。”
- 出错时说清发生了什么、怎么处理，不道歉，不含糊，比如“保存失败：{原因}”“无法连接服务器，请检查网络后重试”。
- 错误信息统一写成“{操作}失败：{原因}”；原因说不清时写“{操作}失败，请稍后重试”。可以重试的，统一说“请稍后重试”。
- 系统和第三方的原文（英文报错、错误码、`os error`、堆栈）不直接显示：原生部分和服务端先换成用户能懂的原因，比如“没有权限访问这个位置”“存储空间不足”，原文记进日志，网页的记进控制台。原生部分写好的中文提示已经说了是哪一步，原样显示；服务端返回的原因跟在“{操作}失败：”后面，表单里的错误紧挨着输入框，直接写原因。模型接口返回的错误例外：先说明状态码的含义，再在括号里附上原话，见 [AI 整理](ai.md#模型配置)。
- 页面崩溃时显示“页面出错”和“重新加载”，错误原文收在下面的“错误详情”里，供反馈问题时使用。
- 中文标点，中文与英文、数字之间留空格。
