# 附件

[附件](../design/attachments.md)在详情里描述下面一组：

- 标题“附件”。图片排成方形缩略图，手机上一行 3 个，电脑上随详情栏的宽度每个至少 80（默认宽度一行 4 个），圆角 10，间隔 6；其他文件一行一个：类型图标、文件名（太长时省略）、大小（“320 KB”“1.2 MB”）。最后一行是主色的“添加附件”：手机上弹出菜单“拍照”“相册”“文件”，电脑上直接打开选文件的窗口，可以多选。
- 刚加的附件马上显示。还没上传完时，缩略图右下角叠一个小图标：在传是转圈，离线时是带斜线的云；文件行的大小换成“等待上传”。上传被拒绝（比如超过服务器或反向代理允许的大小，重试也不会成功）时，提示条写明哪个、为什么，附件随之去掉；AI 整理请求带的附件被拒绝时，整个请求撤回，原文和附件都放回快速添加栏，传不上去的那个右上角标红，点按显示原因，去掉后可以重新提交。
- 别的设备加的，第一次显示时下载，期间缩略图是浅色底加转圈；离线下载不了时是一个灰色图片图标。这台设备显示不了的图片（格式不支持或文件损坏），缩略图、查看器和待添加的附件里也是这个图标。
- 粘贴：详情开着、焦点不在输入框里时按 ⌘V（Ctrl + V），粘贴的文件加到这一项；在描述的编辑框里粘贴，加为附件的同时在光标处插入引用，没有文件时照常粘贴文字。电脑上把文件拖到详情上也一样，拖到描述的编辑框里时同样插入引用；拖动时详情上盖一层主色虚线框，中间写“松开添加附件”。
- 点缩略图打开图片查看器。点文件行打开文件：App 里交给系统默认的应用（没有能打开的时提示“没有能打开这种文件的应用”），浏览器里图片、PDF 和文本在新标签页打开（文本一律按纯文本显示），其他下载，见[网页端](../web.md#附件)。
- 文件行右边的“…”和右键菜单（缩略图也有右键菜单）：在描述中引用、重命名、拷贝图片、用默认应用打开、保存到…（浏览器里是“下载”）、删除。拷贝图片只有图片有，手机 App 和没有剪贴板接口的浏览器（比如经普通 HTTP 打开的自建服务器）里没有；用默认应用打开只有桌面 App 里的图片有（别的文件点开就是）。删除后提示条附“撤销”。
- 用鼠标时，指针移到缩略图上（或键盘焦点在上面），右上角出现“在描述中引用”和“删除”两个小圆按钮（28，半透明黑底、白色图标）。
- 重命名：弹窗，输入框里预先选中扩展名前面的部分，回车保存；不能为空，不能含 `/` 和 `\`。
- 在描述中引用：正在编辑描述时插在光标处，否则接在描述最后（另起一行），提示条写“已在描述中引用”。
- 拷贝图片：转成 PNG 放进剪贴板，可以粘贴到别的应用，提示条写“已拷贝图片”。

图片查看器：

- 全屏黑底，图片适应窗口、居中。滚轮（包括触控板双指上下滑）以指针为中心缩放（指针在图片外时以图片上离它最近的点为中心），双指捏合、触控板捏合也能缩放，电脑上还可以按 + − 缩放、按 0 回到适应窗口；放大后可以拖动；双击（触屏上双击）在适应窗口和原大小之间切换。
- 点图片外面的黑色区域关闭。没放大时左右滑动切换这一项的其他图片，电脑上用方向键或两侧的 ‹ ›。
- 顶栏：左边是关闭，中间是名称和“2/5”，右边是菜单里的那些操作（在描述中引用、重命名、拷贝图片、用默认应用打开、保存、删除）的图标按钮，各端有哪些和菜单一样；⌘C（Ctrl + C）也是拷贝图片。删除后关闭查看器，提示条附“撤销”。返回键和 Esc 关闭。
- macOS 的 App 里，顶栏左边让出窗口的红黄绿三个按钮，拖顶栏可以移动窗口。
- 打开时淡入，关闭时淡出，和其他浮层一样。

描述里的引用：

- 预览时是一个小标签：高 22，圆角 6，secondary-container 底色，前面是图片或文件图标（14），后面是附件现在的名称（最长 16 个字，多了省略）；点了和点那个附件一样。
- 附件已删除，或者不是这个事项的附件时，变灰、名称划掉，写引用里原来的名称，点了没有反应。

快速添加栏里的附件：

- 快速添加栏（和展开的 AI 整理编辑页）里有回形针按钮，点了和详情里的“添加附件”一样：手机上弹出菜单“拍照”“相册”“文件”，电脑上打开选文件的窗口，可以多选。也可以粘贴，或者把文件拖进窗口：拖到详情以外的任何地方都加到这一栏，拖动时栏上盖一层主色虚线框，写“松开添加附件”。没有这一栏的页面（设置、日历的年视图）不接收，指针显示不能放下，松手也不会打开文件。加了以后输入区上方出现一排待添加的附件：图片是 48 的方形缩略图，其他文件是图标加文件名的小标签，右上角有 × 去掉；放不下时这一排横向滚动。
- 直接添加照样要写标题。AI 整理在附件里有模型看得到的图片（见下一条）时，不写文字也能提交，拍一张通知、截一张聊天记录就能整理；都看不到时仍要写内容，发送按钮不可用。提交时新事项带上这些附件，AI 整理的请求也带上，见 [AI 整理](../ai.md#附件)。
- AI 整理时，模型看不到的图片（没打开“识别图片”，或者超过 5 MB、不是 PNG/JPEG/WebP/GIF、第 10 张以后）缩略图左下角标“AI 无法查看”，点按显示原因；它们只把名称和类型发给模型。
- 待添加的附件和草稿的文字一样，各页一份，切换页面、关掉 App 后都还在。
