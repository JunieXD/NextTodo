# 共享文件夹

几个人一起做一个项目时，把一个文件夹共享给大家：里面的事项、子文件夹和先后关系大家都能看、能改，每个人的“接下来”只列自己要做的。

只有连接服务器时能共享，对方要在同一台服务器上有账号（见[邀请其他人](./server#invite)）。在本机使用时没有这个功能。

## 共享一个文件夹

1. 在文件夹的“…”菜单（电脑上也可以右键）里选“共享…”。
2. 输入对方的用户名，点“添加”或按回车。添加后立即生效，不用对方同意。
3. 可以接着添加更多人。

共享后，文件夹换成带两个人的图标，标题右边是共享人和成员的头像，点头像也能打开共享面板。

- 根目录不能共享；共享的文件夹里不能再共享子文件夹，也不能放进别的共享的文件夹。
- 文件夹里的事项和外面的事项之间的先后关系会去掉，共享面板里会事先写明有几条。

## 别人共享给我的

别人共享给你的文件夹在单独一组“共享给我”里：电脑上在左栏文件夹树的下面，手机上在“文件夹”页里。每个文件夹后面写着是谁共享的。

里面的一切你都能看、能改：添加、修改、完成、删除事项和子文件夹，设置先后，设负责人。这个文件夹本身只有共享人能改名、改颜色和图标、移动、删除和管理成员。

## 负责人

共享的文件夹里的事项可以指定负责人，可以是一个人，也可以是几个人：

- 在事项详情的“负责人”一行里勾选，从共享人和成员里选。
- 一次设好多项：文件夹的“…”菜单里选“批量操作”，选中事项后点“负责人”。

设了负责人的事项，列表里右边显示负责人的头像。没设负责人的，所有人都能做。

## 我的事项

“接下来”“已完成”和提醒只看你的事项：你私人的事项，加上共享的文件夹里没设负责人、或者负责人里有你的。交给别人的事项不打扰你，但在文件夹页、关系图和搜索里都看得到。

别人的改动会实时出现，一般不弹提示，只有两种和你有关的例外：

- 有人把你设为负责人：“Alice 将“装灯具”指派给我”。
- 别人完成的事项让你的事项可以开始了：“Bob 完成了“铺地砖”，解锁了“装灯具””。

点提示条上的“查看”打开那一项。事项详情的底部写着是谁添加、谁最后修改的。

## 移进和移出

事项和文件夹可以在共享的文件夹和私人的文件夹之间移动。先后关系只能连在同一处（私人的事项之间，或同一个共享的文件夹里），所以移进、移出时：

- 连到外面的先后关系去掉；
- 新地方看不到它的人不再是负责人（移到私人的文件夹时负责人全部去掉）。

提示条会写明去掉了什么，点“撤销”一起恢复。

## 退出和停止共享

- **成员退出**：在共享面板里点“退出共享”。退出后看不到这个文件夹，要共享人重新添加才能回来。
- **共享人移除成员**：在共享面板里点那个人右边的“移除”，可以撤销。
- **停止共享**：共享人在共享面板左下角点“停止共享”，所有成员都看不到这个文件夹了，事项的负责人一并去掉，可以撤销。

有人离开时，这个人负责的事项去掉这个负责人；这个人提交的、还没整理完的 [AI 整理](./ai)请求改放到自己的根目录。

## 撤销

看得到一次改动的全部内容、也有权做这些改动的人都能撤销它：别人的 agent 在共享的文件夹里改错了，你也能撤销。添加、移除成员只有共享人能撤销。

## 让 agent 帮忙分工

[接入的 agent](./agent) 也能管理共享的文件夹：别人共享给你的文件夹写成 `@alice/装修`，里面的事项用共享人的编号，写成 `@alice#42`。比如：

```sh
nexttodo share /装修 bob              # 把“装修”共享给 bob
nexttodo add "买瓷砖" --folder /装修 --assign bob
nexttodo edit @alice#42 --assign bob   # 别人共享给我的文件夹里的事项
```
