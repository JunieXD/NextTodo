# 在本机使用

不部署服务器也能用：Android、iOS、macOS 和 Windows App 可以只在本机使用，不用注册账号，数据存在这台设备上。几台设备之间可以[借网盘同步](#drive)。

## 和连接服务器的区别

- **同步**：默认不同步，每台设备的数据各自独立。[借网盘同步](#drive)时，改动几十秒内到别的设备，不是实时。
- **没有网页版**：网页版只能连接服务器。
- **没有共享文件夹和多账号**：只有自己一个人用。
- **agent**：只能在电脑上接入，见[接入 agent](./agent#在本机使用时)。手机上不能。
- **AI 整理**：配置只保存在这台设备上。
- **更新**：App 从 GitHub 获取新版本。

其余功能完全一样。

## 开始

第一次打开 App 时选“在本机使用”即可。已经登录了服务器的，先在“设置 → 账号”最下方退出登录，再在登录页选“在本机使用”。

## 借网盘同步 {#drive}

手机和电脑都在本机使用时，可以借一个网盘在它们之间同步，不用部署服务器。支持 WebDAV 网盘（如坚果云）和 S3 兼容的对象存储（如 MinIO）。开启时会先检查这个网盘能不能用来同步，不能用的会提示原因。

### 第一台设备

1. 打开“设置”，点最上面的“本机模式”，再点“借网盘同步”。
2. 选择网盘，填好下面几项：
   - **WebDAV**：地址、用户名、密码。坚果云的地址已经填好，不用改；密码要用坚果云的应用密码，不是登录密码，见下文。
   - **S3**：接口地址、区域、存储桶、Access Key ID 和 Secret Access Key。“地址风格”一般不用改，MinIO 这类自建的选“路径”。存储桶不能开启版本控制，否则无法同步。
   - **文件夹**：数据放在网盘里的这个文件夹，默认是 `NextTodo`，不存在会自动新建。要用一个空文件夹。
3. 点“开启同步”。这台设备上的数据会传到网盘里。

### 其他设备

在其他设备上按同样的步骤，填同一个网盘和同一个文件夹。开启时会提示“用网盘里的数据替换这台设备上的全部数据？”，确认后 App 重新启动，换上网盘里的数据。这台设备原来的数据不会合并进去，所以先在数据最全的那台设备上开启。电脑上接入过 agent 的，换上网盘里的数据后要重新生成令牌。

### 坚果云的应用密码

1. 用浏览器登录[坚果云网页版](https://www.jianguoyun.com)，点右上角的账户名，进“账户信息”。
2. 打开“安全选项”，在“第三方应用管理”里点“添加应用密码”，名称随便写（比如 NextTodo），点“生成密码”。
3. 用户名填坚果云的登录邮箱，密码填刚生成的应用密码。

坚果云的免费版限制了请求次数和每月的流量。每台设备平时 30 秒查一次，几台设备一起用也在免费版的限额以内；附件最占流量。

### 使用时

- 改动在这台设备上立即生效，几十秒内同步到别的设备；App 回到前台时会马上同步一次。没联网时照常使用，联网后自动补上。
- 别的设备添加的附件，第一次打开时才从网盘下载。
- 手机上“接下来”大标题下面、电脑上左栏左下角的名字下面，写着上次同步是多久以前；想马上看到别的设备刚做的改动，手机上点这一行，电脑上点这一行右端的同步按钮，立即同步。同步受阻时这里写着原因，比如“同步受阻：无法连接网盘”。
- “设置”里的本机模式卡片写着同步到哪个网盘、上次同步的时间，出错时写明原因。
- AI 整理的配置可以随网盘同步到每台设备，见 [AI 整理](./ai)；默认提醒、主题色这类[跟着账号的设置](./basics#prefs)也随网盘同步。
- 网盘里的数据不加密，网盘的服务商看得到内容。

### 停止同步

在“借网盘同步”里点“停止同步”。这台设备上的数据留着，之后的改动只在这台设备上，网盘里的不动。停止前会先把还没下载到这台设备的附件下载下来；下载不了时会提示，这时仍然停止，这些附件之后就打不开了，最好等联网后再停止。再开启时，会用网盘里的数据替换这台设备上的数据。

## 备份 {#backup}

没有借网盘同步时，数据只在这台设备上，设备丢了或坏了，数据也就没了。请定期备份，把备份文件存到别处，比如网盘或另一台电脑。

1. 打开“设置”，点最上面的“本机模式”，再点“备份”。
2. 选择保存的位置。备份文件名是 `NextTodo-备份-<日期>.tar`，以前的版本备份的 `.db` 文件也能恢复。

备份里有全部事项、文件夹、附件、改动记录和令牌，不含 AI 整理的配置和 API 密钥。

## 恢复

用备份替换这台设备上现在的全部数据：

1. 打开“设置 → 本机模式”，点“恢复”，选择备份文件。
2. 确认替换。App 会重新启动，打开后就是备份时的数据。

恢复前的数据不会删除，仍留在 App 的数据目录里。借网盘同步时不能恢复，要先停止同步。

换了新设备时，在新设备上选“在本机使用”，再恢复旧设备的备份，就能接着用。

App 无法启动时，页面上也有“恢复备份”按钮。

## 改用服务器

在“设置 → 本机模式”里点“改用服务器”，App 会重新启动，回到登录页。本机的数据保留在这台设备上，以后再选“在本机使用”可以接着用，但不会自动搬到服务器上，要搬见下一节。借网盘同步的，改用服务器期间同步停下，回到本机使用后接着同步。

## 搬到服务器和搬回本机 {#move}

数据可以用备份文件在本机和服务器之间搬：

- **本机 → 服务器**：先在“设置 → 本机模式”里点“备份”；改用服务器、登录以后，点设置最上面的账号（头像和名字），再点“导入备份”，选这个文件。数据作为一份新的加进这个账号，账号里原有的不动，所以同一个文件导入两次就是两份；导入可以撤销。
- **服务器 → 本机**：在同一处点“导出备份”；进入本机模式以后，在“设置 → 本机模式”里点“恢复”，选这个文件。它会替换这台设备上现在的数据。

导出的是你自己的文件夹和事项，连同它们的附件和完成记录；共享出去的文件夹照样带上，但不带成员和负责人。别人共享给你的文件夹、改动记录和令牌不带，所以它不是整台服务器的备份。导出的文件也能导入另一台服务器或另一个账号。
