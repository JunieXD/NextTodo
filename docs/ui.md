# 界面

视觉和交互的规格。定规格时用的可点击原型在正式前端做出来以后删掉了，要看可以在提交 `57a07ad` 里找。

## 设计方向

- **一处大胆，其余克制**：文件夹列表左侧的“轨道”是唯一的视觉重点，其他地方保持安静。
- **颜色有含义**：主色翡翠绿只表示“可做”；等待中用中性灰和虚线；逾期红，今天到期琥珀色。不用颜色做装饰。
- **Material 3 的配色和组件，iOS 的结构和手势**：Material 3 的颜色角色、导航指示条、筛选标签、悬浮按钮、对话框；iOS 的大标题、圆角分组列表、可拖动的底部面板、滑动操作。
- **动效只回应操作**：只在用户操作后出现，用来说明发生了什么变化；没有自动播放的装饰动画。

## 圆角、间距、阴影

- 圆角按层级区分：底部面板和对话框 28，快速添加栏 25（胶囊），其中的输入区 20，悬浮按钮 16，分组列表和关系图节点 14，分段控件 10（选中项 8），筛选标签和文件夹图标 8，描述里的清单框 5，事项勾选框为圆形。
- 左边对齐两条线：页面和弹窗的标题、正文、空列表的提示、输入框和分组列表对齐同一条边（手机、底部面板和弹窗里 16，电脑主区 28，菜单栏小窗的列表 12）；居中的确认框是一张小卡片，标题、正文和按钮在里面统一用 24。分组标题和分组下面的注释再缩进 16，和行里的文字对齐。表单页里另起的一组（如 AI 整理的“说明”）用输入框标题的样式，不用分组标题。普通行最小高 56，轨道列表行高固定 64。行左边的名称不压窄，右边的值（如设置首页的模型名、写入日历的文件夹）放不下时以省略号截断。
- 分隔线 0.5px，从文字起点开始，不贯穿图标。
- 左栏各项之间留 2 的间隙，选中项和悬停的相邻项不粘在一起。
- 阴影只用两级：分段控件选中项用一级，浮在内容上的元素（快速添加栏、悬浮按钮、提示条）用三级。

## 布局

| | 手机（窄于 1000px） | 电脑（1000px 及以上） |
|---|---|---|
| 结构 | 顶部栏 + 内容 + 底部栏 | 左栏 + 中栏 + 详情栏，左右两栏可以拖动调宽 |
| 导航 | 底部栏四项：接下来、[日历](#日历)、文件夹、设置（图标是头像） | 左栏：接下来、已完成、日历、“文件夹”下的文件夹树、[“共享给我”](#共享)、搜索；设置在左栏左下角（头像和名字），在中栏打开 |
| 收起 | | 中栏顶部左侧的按钮收起或展开左栏，带过渡 |
| 详情 | 底部面板 | 详情栏：默认收起，点事项时滑出，再点同一项或关闭按钮收回；详情开着时点别的事项直接换内容，不播动画 |
| 快速添加 | 浮在底部栏上方 | 中栏标题下方 |

- 电脑上左栏和详情栏的宽度可以拖动：指针移到它和中栏之间的分隔线上变成左右箭头，分隔线高亮，按住左右拖；双击分隔线恢复默认宽度。左栏 200–400（默认 272），详情栏 320–600（默认 400），中栏至少留 320，收着的那一栏不占地方：拖详情栏到中栏只剩 320 时停住，不挤左栏；拖左栏到中栏只剩 320 后，接着收窄详情栏，直到它的下限。放不下时（窗口变窄，或打开收着的一栏）先收窄详情栏，再收窄左栏，都不小于下限；地方又够了（窗口变宽，或收起另一栏）就回到选的宽度，所以收起一栏时，另一栏没被挤窄的不变，被挤窄过的回到选的宽度，其余让出的地方给中栏。宽度存在这台设备上，被挤窄的不算选过。
- 手机顶部栏高 56（加安全区），滚动前透明，向下滚过大标题后显示毛玻璃背景、分隔线和居中的小标题。
- 进入文件夹、从“接下来”进入“已完成”、进入[设置](#设置)的子页时，新页面从右侧滑入，返回时反向。电脑上换到左栏的另一处，或在列表和关系图之间切换时，中栏淡入（0.2 秒）。
- 文件夹树的顶层是根目录（图标与文件夹区分），展开是顶层的文件夹；计数是里面的待办数，含子文件夹里的，所以根目录的是全部的待办（别人共享给我的除外）。不能新建和根目录同级的文件夹。别人共享给我的文件夹不在树里，在下面的“共享给我”一组，见[共享](#共享)。
- 手机“接下来”页的大标题右侧有“已完成”按钮（历史图标）。

### 返回

Android 的返回键（含侧滑返回）一次退一步：

1. 先关掉最后打开的东西：对话框、弹窗、展开的 AI 整理编辑页、文件夹菜单、关系图的连线状态、事项详情，再退出[批量操作](#批量操作)。
2. 都关了以后，在文件夹里回到上一级，在“已完成”回到“接下来”，在设置的子页回到设置首页。
3. 在底部栏的页面（“接下来”“日历”“文件夹”“设置”）之间切换不算一步，再按返回就退到后台。

网页的返回按地址的历史记录走，打开详情会加一条记录，所以返回也会先关掉详情。

### 改动记录

设置里的一个子页，地址 `/settings/log`，内容见[改动记录和撤销](design.md#改动记录和撤销)。

- 标题下面是“全部、已删除”的分段控件。
- 列表按天分组，组标题写“今天”“昨天”“11月20日 周五”（不是今年的加上年份）。每条一行写改了什么（只占一行，放不下时末尾省略），下面一行灰色小字写谁做的、几点和批次号，如“Claude Code · 14:32 · 批次 78”“本人（iPhone） · 09:05 · 批次 3”，放不下时省略来源的末尾，几点和批次号总是写全：撤销别的批次的写成“撤销批次 79：……”，按批次号就能对上是哪一条；右边是“撤销”文字按钮，已经撤销了的换成灰色的“已撤销”。点这一条的其他地方打开“改动详情”。
- 改动详情是弹窗。上面一组：“来源”（同列表里的写法）、“时间”（“11月22日 17:09”，不是今年的加上年份）、“批次”；撤销别的批次的，再多一行“撤销的批次”。下面一组标题是“改动”，每类改动一行，列出全部事项（列表里每类最多写 3 个），放不下时换行；什么也没改的写“没有变化”。底部固定着“撤销”文字按钮，改动多时不随内容滚走，和列表里的按钮一样；撤销后弹窗不关，按钮换成灰色的“已撤销”。打开时向服务端取这一批（`log` 的 `batch`），取的时候写“正在读取…”，失败时写原因，附“重试”；这一批已不在记录里（超过 90 天）时写“这个批次已不在改动记录里”，不能撤销。
- 点“撤销”由服务端撤销那个批次（同 `undo`），所以很早的、别的设备上做的也能撤销；等回应时按钮不能点，成功后这一条变成“已撤销”，提示条写“已撤销”；那次改的东西已经不在或改回去了的（比如加的事项后来删掉了），提示条写“没有变化”，这一条不变；失败时写原因，比如批次里有无权查看的改动。
- 一次取 50 条，到底时有“加载更多”。改动同步过来时（包括刚撤销的）从头重新取，已经加载的几页一起取，看到的位置不变。都没有时写“90 天内暂无改动”（已删除里写“90 天内暂无删除”）。连不上服务器时写原因，附“重试”。
- 摘要里的文件夹路径按当时的名称写，但在已删除里、翻到后面的页里和改动详情里，之后改过名的文件夹写现在的路径。

### 隐私锁

设置里的一个子页，地址 `/settings/lock`，规则见[隐私锁](design.md#隐私锁)。

- 最上面是“隐私锁”开关，小字写“闲置一段时间后锁定 NextTodo，用 PIN 解锁。仅防他人查看，不加密数据”。网页经 HTTP 打开时没有开关，只写“经 HTTP 打开时无法使用隐私锁，请改用 HTTPS”。
- 打开开关时弹出“设置 PIN”弹窗，分三步：输入 4 到 6 位数字点“下一步”；再输一遍点“下一步”，两次不同时提示“两次输入的不一样”，回到第一步；然后是恢复码。在恢复码这一步点“我已存好”才开启，之前关掉弹窗就不开。
- 恢复码：16 个字母和数字，每 4 个一组，用短横线连起来，如 `7KQ2-M9XD-4TPW-H3RC`，不用 0、O、1、I、L、U 这些容易看混的。弹窗里用等宽字显示，旁边是“复制”，下面写“忘记 PIN 时用它解锁。仅显示这一次，请存入密码管理器或另行记录”。输入时不分大小写，空格和短横线可有可无。
- 开着时，开关下面一组：“闲置多久锁定”（1、5、15、30 分钟的分段控件）、“修改 PIN”（同样的弹窗，没有恢复码那一步）、“换一个恢复码”（弹窗显示新的恢复码，写“点‘我已存好’后，旧的恢复码随即失效”，关掉弹窗就不换）；再下面一组是“立即锁定”。关掉开关就去掉锁，不用输 PIN：看得到这一页，说明已经解锁了。
- 电脑布局左栏左下角，头像那一行的右边有锁的图标按钮，提示“锁定”，开了隐私锁才有。
- **锁屏**：整个窗口是背景色，正中从上到下：App 图标、“NextTodo 已锁定”、PIN 输入框（显示成圆点，手机和平板上弹出数字键盘）。输够位数自动解锁，也可以按回车；错了清空，下面红字写“PIN 错误，还可尝试 3 次”。最下面是“忘记 PIN？”文字按钮。
  - 点“忘记 PIN？”或连错 5 次以后，输入框换成“恢复码”和“解锁”按钮：恢复码在本机核对，不发给服务器；不对时写“恢复码错误”。连服务器时下面有“用账号密码解锁”，点了换成“账号密码”输入框，由服务器核对（不对时写“密码错误”，连不上时写原因），再点“用恢复码解锁”换回来。连错了 5 次的上面写“PIN 已连续错误 5 次，请用恢复码或账号密码解锁”（本机模式下没有“或账号密码”）；没错满的有“输入 PIN”文字按钮回去。
  - 对了以后是“设一个新的 PIN”：输两遍，同设置里的前两步，设好就解锁。
  - 菜单栏小窗里是同一个锁屏，按小窗的大小排。

### 日历

[按日期看](design.md#日历)事项，地址是 `/calendar`。手机上是底部栏第二项（日历图标），电脑上在左栏“已完成”下面，在中栏打开，和设置一样是居中的一栏（最宽 600）。

- 标题行：大标题“日历”，右边是“月、周、年”的分段控件。下面一行是“2026年11月”（年视图是“2026年”），右边是“今天”（看的不是今天所在的月、周、年时才有）和换月（周、年）的 ‹ ›。选择的视图存在这台设备上。
- 月、周的格子：一周 7 列撑满宽度，每格高 56，整格都能点；里面每天是一块圆角 12 的方块，宽 48（列宽不到 54 时是列宽减 6）、高 50，方块之间留着空隙，涂了色的也不连成一片。从上到下是日期数字、[农历](design.md#农历)小字（初一写月份）、那天截止的小圆点（最多 3 个，直径 4，逾期的用 error 色）。前后月份的日子颜色淡一些，也能点。今天的数字用主色加粗；选中的那天加 2 的主色描边。
- 热力图：今天和以前完成过事项的日子，方块涂上底色，4 档由浅到深：一半的 primary-container、primary-container、primary-container 上叠 12% 和 24% 的主色（深色主题叠 7% 和 14%）。文字颜色不变，最深一档上的农历小字和今天的主色数字也看得清。前后月份的日子不涂（淡色的字在底色上看不清），切到那个月再看。
- 年视图：12 个小月历，手机上一行 3 个，电脑上一行 4 个；每个上面写“1月”，下面是 7 列的小方格（12×12，圆角 3，间距 2），一天一格，每格是 surface-container 的底，完成过的按 4 档叠上主色，格子小，颜色比月视图深，不透明度 30%、50%、70%、100%；今天加主色描边。点一格切到月视图的那一天。
- 下面的列表：选中那天的标题（“11月20日 星期五 · 十月十二”），分两组“截止”和“完成”，没有的组不显示；都没有时写“这天没有事项”（灰色）。行同[事项行](#事项行)：截止的照常可以勾；重复事项以后的一次，勾选圈换成虚线圈、不能点，次要信息写“以后的一次”；完成的事项划掉，点勾选圈恢复成待办；重复事项的完成记录写“完成一次”，后面是按时、“晚 3 天”或“提前 2 天”，勾选圈是实心的、不能点。点行打开详情。
- 手机上左右滑动格子换月（周、年），和点 ‹ › 一样。

### “接下来”的文件夹筛选

[只看某些文件夹](design.md#接下来)里可做的事项。

- 入口：标题行右边的筛选按钮，和那里的图标按钮放在一起：电脑上在标题右边，手机上在“已完成”左边，菜单栏小窗在“在主窗口打开”左边。不筛选时只是一个灰色的筛选图标；筛选时变成浅色底（secondary-container）的小胶囊，筛选图标后面写选中的名字：一个写它的名字，两个写“工作、学习”，更多写“3 个文件夹”，太长时省略。悬停提示“筛选文件夹”，筛选时后面带上选中的全部名字。
- 点开是弹窗“筛选文件夹”，和 Android 设置里[写进系统日历](android.md#写进系统日历)的“写入的文件夹”是同一个：根目录和全部文件夹，按层缩进，共享给我的在后面一组，每行右边是复选框。勾了一个文件夹，它里面的文件夹也打勾、变淡，表示已经包括；勾根目录就是全部文件夹，不筛选，要只看某些文件夹先去掉它的勾。勾选立即生效，点外面或下拉关闭弹窗；一个都没勾就关掉时回到全部文件夹。
- 选中的文件夹删除了、退出了共享，就不再算在选择里，都没了时回到全部文件夹；它回来了（撤销删除、重新共享给我）又算在选择里。
- 筛选后没有可做的事项时，列表的位置写“这些文件夹里现在没有能做的事”，下面是主色文字的“看全部”，点了回到全部文件夹。
- 筛选时，快速添加的目标文件夹默认是选中的第一个（按文件夹树从上往下），新加的事项不会一加就看不见。
- 选择按用户存在这台设备上，菜单栏小窗和主窗口共用一个选择。

### 事项行

- 勾选圆圈：可做是主色实线圈；等待中是轨道色虚线圈；已完成是主色实心并带对勾。触摸区域向外扩到 44。
- 标题单行，超出省略。“接下来”里有前置或后续的事项，标题后面跟着次要文字色的[关联进度](design.md#关联进度)“2/5”，标题太长时先省略标题，进度总是完整显示。
- 下面一行次要信息依次是：文件夹路径（只在“接下来”和搜索结果里显示）、“今天已完成”（今天完成过、截止已经到明天以后的重复事项，主色）、截止时间（重复的事项用循环图标代替时钟）、“等 N 项”、还没到开始时间的“20:00 开始”“明天开始”“周五 09:30 开始”“11 月 14 日开始”（写法同截止时间）、“解锁 N 项”（做完它马上能开始的后续数，为 0 不显示）、回形针和附件数（没有附件不显示）。

### 文件夹的颜色和图标

[文件夹可以选颜色和图标](design.md#文件夹)，都是预设的。界面规格说“不用颜色做装饰”，这是用户自己选的例外，只用在文件夹的图标上。

- 颜色 12 种：红、橙、琥珀、黄、草绿、绿、青绿、青、蓝、靛蓝、紫、粉（`red`、`orange`、`amber`、`yellow`、`lime`、`green`、`teal`、`cyan`、`blue`、`indigo`、`purple`、`pink`）。每种是一组 Material 3 色调（HCT 色相依次 25、50、72、95、120、145、180、210、260、285、310、350，色度 48）：图标底用 90（深色 30），底上的图标用 10（深色 90），直接画在页面上的图标用 40（深色 80）。没选颜色的用主色，和现在一样。
- 图标 40 个（Lucide）：公文包、学士帽、书、笔、文档、笔记本电脑、代码、烧瓶、计算器、灯泡、靶心；房子、购物车、餐具、咖啡、衣服、婴儿、爪印、心、礼物；哑铃、自行车、心跳、药丸；钱包、存钱罐；飞机、汽车、地点；音乐、相机、调色板、游戏手柄；星、旗、火箭、奖杯、扳手、叶子、人群。没选图标的是文件夹图标（共享的文件夹是带两个人的文件夹），和现在一样。
- 本来有文件夹图标的地方换成选的：文件夹列表的方块图标（底和图标用这个颜色）、电脑左栏的文件夹树（图标用这个颜色）、选文件夹的弹窗。本来没有图标的地方，选了颜色或图标才加上：文件夹页的大标题前面一个方块图标（28，手机 32），“接下来”和搜索结果里事项的文件夹路径、详情的“文件夹”一行前面一个小图标（14）。
- 设置：文件夹的“…”菜单和右键菜单里的“颜色和图标…”（在“重命名”后面；共享的文件夹本身只有共享人有这一项），打开弹窗“颜色和图标”。顶上是预览：方块图标和文件夹名。下面“颜色”一组：第一个是“默认”（空心圆，文件夹用主色），后面 12 个圆点，选中的带对勾；“图标”一组：第一个是“默认”（文件夹图标），后面 40 个图标，一行排满为止，选中的用浅色底（secondary-container）。按钮“保存”，改动是一次，可以撤销。

### 轨道

文件夹列表按依赖顺序排列，左侧画类似 git 提交图的轨道：

- 勾选圆圈就是轨道上的节点；依赖沿轨道从前置所在行连到后续所在行，并行的支线分开成几列，列宽 24。
- 像地铁线路图那样合并线路：一个事项有几个后续时，共用一条轨道，到各个后续处分出去；几个只有这一个后续的事项指向同一项时，汇成一条轨道再接进去。常见的“一对多”“多对一”只占两列。合并有时会让分出去的线横穿别的轨道：两种合并都做、只做一种、都不做，四种排法里取交叉最少的，一样时取列数最少的。
- 合并后仍超过上限（手机 3 列、电脑 5 列）时，这个文件夹的列表不画连线，勾选圆圈排成一列，顶上一行“依赖较多，列表里不画连线”，点它切到关系图。
- 只画文件夹内、未完成事项之间的依赖，冗余的依赖不画（同关系图）。
- 从可做事项出发的线用主色（65% 不透明），其余用轨道色。
- 文字起点随轨道列数后移，分隔线跟着对齐。

### 关系图

- 布局：正式版用 ELK Layered，在实现时用真实数据对比几组参数调到最好。要求：连线不穿过节点，交叉尽量少，链条尽量直，可做的事项排在第一层。手机从上到下排，电脑从左到右排。
- 节点：可做用 primary-container 填充；等待中是白底描边；已完成灰底划掉；文件夹外的事项虚线框、半透明，上方标注所在文件夹。标题下面一行次要信息只放得下一样，依次取第一个有的：还没到开始时间的“11 月 20 日 09:30 开始”（连线看不出它在等什么；开始不晚于截止，这时截止也不会已经逾期）、截止时间、等待中的“等 N 项”。设了负责人的，这一行右端叠放负责人的头像（16），最多 2 个，再多写“+N”。手机节点宽 104–146（按屏幕宽度自适应），电脑 184，高 60。
- 选中节点外加主色描边；不在它前后链上的节点降到 28% 不透明，链上的连线变主色并加粗。
- 画布背景是随平移和缩放移动的网点。
- 手势：单指或鼠标拖动平移；双指捏合缩放（以两指中点为中心，同时可以平移）；触控板双指滑动平移，捏合或 Ctrl + 滚轮缩放。缩放范围 0.35–2.5。拖动之后不触发点击。
- 连线：点“连线”后依次点前置和后续，顶部提示当前步骤，前置节点会有脉冲光圈。连出循环时拒绝，并列出环上的事项。
- 点连线弹出删除确认。

### 底部面板（手机详情）

- 两档：半开（屏幕高的 60%）和全开。半开时不遮暗背景，可以继续点后面的列表或节点，详情跟着切换；全开时背景变暗。
- 从任何位置都能拖：内容滚到顶以后继续下拉，就是拖动面板；半开时上推会先展开到全开。快速下甩：全开降到半开，半开直接关闭。
- 半开时内容也能完整滚到底。
- 拖到关闭时，面板从松手的位置继续滑下去。

### 弹窗、对话框、提示条

- 弹窗（选文件夹、选前置后续、修改密码、生成令牌、附件重命名）：手机上是底部面板，电脑上是居中的 440 宽卡片。打开时播放一次动画，之后界面刷新不再重播。
- 选文件夹：列出根目录和全部文件夹，按层缩进，共享给我的文件夹在后面单独一组“共享给我”。“移动到…”里，事项或文件夹现在所在的文件夹打着勾、变淡，不能选；移动文件夹时，它自己和它里面的文件夹也变淡，不能选；移动共享的文件夹或里面有共享的文件夹时，共享的文件夹和它们里面的也变淡，不能选。快速添加的“添加到”里，打勾的是已选的目标。Android 设置里[写进系统日历](android.md#写进系统日历)的“写入的文件夹”每行是勾选框，可以勾几个。
- 选前置后续：只列能连的事项，即同一处的（私人的事项，或同一个共享的文件夹里的，见[依赖](design.md#依赖)）。和文件夹页一样分层，从事项所在的文件夹开始（共享的文件夹里的事项最多回到那个共享的文件夹），先列子文件夹（只列里面有可选事项的，注明几项），再列这个文件夹里的事项；顶上一行回到上一级。换一层时搜索框不动，面板不动，下面的内容左右切换（进入子文件夹从右侧进，回到上一级从左侧进），从顶上开始显示；开始和清空搜索时也从顶上开始。已经连上的不列出；已完成的也列出，可以把事项和它的来龙去脉连起来，划掉显示，每一层排在未完成的后面，最近完成的在前，搜索结果里也排在后面。连上会成环的列出但不能选。搜索时在同一处的所有文件夹里找标题和详情，结果注明所在文件夹。搜索框里有文字时，最上面一行是主色的“新建“××””，下面注明放在哪个文件夹（面板当前所在的，一开始就是这个事项所在的）；点它新建这一项并连上，新建和连上是同一次改动，一起撤销。
- 截止时间弹窗：上面是月历，下面一组设置行（样式同设置页的行）：
  - 月历：一周从周一开始，顶上是“2026年11月”和换月的 ‹ ›；固定 6 行，前后月份的日期颜色淡一些，也能点。每天的数字下面是小一号的[农历](design.md#农历)日子（“十二”“廿三”），初一写月份（“冬月”“闰六月”）。今天用主色文字，选中的日期是主色实心的圆角方块。用键盘时方向键换日期。开始时间、重复到的月历也一样。
  - 时间：右边是“18:00”或“不设时间”（截止到当天结束），点开是[时间选择](#其他)。
  - 提醒：可以多选，见[提醒](design.md#提醒)。点开的菜单里点一项打勾或去掉勾，菜单不收起，点外面收起。有具体时间的，菜单是截止时、提前 5、15、30 分钟、1、2 小时、1、2、7 天；只有日期的，是当天 09:00、前一天 20:00、前一天 09:00、提前 2 天 09:00、提前 7 天 09:00。最上面是“不提醒”（没有提醒时打勾，点了去掉全部），最下面是“自定义…”。不在菜单里的提醒（自定义的，或 agent 设的提前 90 分钟）也打着勾列在菜单里，按时刻排在其他项之间。
    - 选“自定义…”收起菜单，下面多出几行：有具体时间的先是“提前多久”“按日子”的分段控件，只有日期的没有这一行，只能按日子；提前多久是数字加减和“分钟、小时、天”的分段控件，最多提前 30 天；按日子是“提前几天”的数字加减（0–30，0 是当天）和“几点”（点开是[时间选择](#其他)，默认 09:00）。最后一行右边是“添加”，加上后这几行收起；已经有的不重复加。
    - 这一行右边按时刻先后写提醒，只占一行：两个以内全写，用“、”隔开，如“前一天 20:00、当天 09:00”“提前 1 天、截止时”；更多时写第一个和总数，如“提前 7 天 09:00 等 7 个”，全部的点开菜单看；还放不下时末尾省略；没有的写“不提醒”。菜单最高 400 像素，选项多时在菜单里滚动。最多 100 个，选多了时点“保存”在弹窗里提示“提醒最多 100 个”，弹窗不关。提前多久写成“提前 90 分钟”“提前 3 小时”“提前 2 天”，能整除的用大的单位；按日子写成“当天 09:00”“前一天 20:00”“提前 3 天 09:00”。详情里“提醒”一行也这样写。
    - 去掉时间时，提前多久的提醒一起去掉。事项原来没有截止时间的，提醒预先选好这台设备的默认提醒（有时间、只有日期的各用各的，在弹窗里加上或去掉时间时跟着换），手动改过提醒以后不再跟着换。
  - 重复：不重复、每天、每个工作日、每周、每月、每年和自定义；已完成的事项不能设，写“已完成的事项不能重复”。“每年”就是每 12 个月。选自定义多出“间隔”一行：数字加减（1–365）和“天、周、个月”的分段控件。按周重复时（每周，或自定义的单位是周）多一行“周几”：一到日七个圆形开关，可多选，默认是截止日期那天，最后一个不能关掉；选了周几，菜单就显示成选的日子，如“每个工作日”“每周一、三、五”“每 2 周的周二、四”。按月重复时（每月，或自定义的单位是个月）同样多一行“几号”：1 到 31 号的圆形开关，一行 7 个，用法和周几一样；选了几号，菜单显示成“每月 1、15 号”“每 2 个月的 27、28 号”。按月重复和每年（每月、每年，或自定义的单位是个月）在“几号”上面多一行“按农历”开关，小字写截止日期的农历（“截止日期是农历十月十七”），见[重复](design.md#重复)：打开后“几号”一行一定出现，换成初一到三十，默认是截止日期那天的农历日子；菜单显示成“农历每月初一、十五”“农历每 2 个月的初一”“每年农历八月十五”“每 2 年的农历八月十五”（月份取截止日期的农历月，闰月写成同名的月份）。再选别的项（如“每周”“自定义”）就回到不选周几或几号，也不按农历。设了重复再多一行“下一次从”：“截止日期算”或“完成那天算”。重复写出来是“每个工作日”“每周一、三、五”“每 2 周的周二、四”“每月 27、28 号”这样；没动过周几、几号的是普通的每周、每月，写成“每周”“每月”，跟着截止日期；12 个月的倍数没选几号的写成“每年”“每 2 年”；按农历的写法同上面的菜单。
  - 重复到：设了重复才有，在“下一次从”下面；见[重复](design.md#重复)。右边是“一直重复”或日期，如“12 月 19 日”，写法同截止时间。点开是月历，截止日期之前的日子变淡、不能点，点一天就收起；底部是“一直重复”。上面的月历把截止日期改到这天之后的，保存时提示“重复到不能早于截止”，不保存。
  - 详情里截止时间一行写成“11 月 10 日 18:00”，设了截止的下面一行是“提醒”（没有的写“不提醒”，灰色）；重复的事项在提醒下面多一行“重复”，写成“每周”，设了重复到的写成“每天，到 12 月 19 日”，点开也是这个弹窗。
  - “提前”“间隔”“周几”“几号”“下一次从”这几行，名称和右边的控件并排放不下时（屏幕窄或字号大），控件换到名称下面一行，靠右排；控件之间也放不下时再各占一行，名称和按钮上的字都不压窄。
  - 设了开始时间的，月历里开始那天之前的日子变淡，不能点；和开始同一天、几点早于开始的，保存时在时间一行下面提示“截止不能早于开始”，不保存。
- 开始时间弹窗：详情里“截止”上面的“开始”一行（没设时写“未设置”，灰色）打开它。上面是月历，截止日期之后的日子变淡，不能点；下面是“时间”一行，右边是“09:30”或“不设时间”（从当天 0 点开始），同截止时间的。和截止同一天、几点晚于截止的，保存时同样提示“开始不能晚于截止”。底部左边是红色文字的“清除开始时间”，右边是“保存”。详情里这一行写成“11 月 14 日 09:30”。
- 复制文件夹：文件夹的“…”菜单和右键菜单里的“复制…”打开小弹窗“复制“签合同””，一个“名称”输入框，预先填好副本的名字（规则见[文件夹](design.md#文件夹)）并全选，下面一行说明“连同子文件夹、事项、附件和先后关系一起复制，事项都变回待办”，按钮“复制”。副本紧跟在原文件夹后面（别人共享给我的复制到根目录的最后），提示条写“已复制为“签合同 副本””，附“撤销”。
- 详情顶部的状态后面写等的是什么：“还有 2 项前置未完成”“11 月 14 日开始”，两样都有时都写。
- 详情里重复的事项在这几行的最后多一行“已完成”：“共 12 次，上次是昨天”，最近一次是今天的写“共 12 次，今天已完成”（补上漏掉的一次以后截止还在今天的，写“上次是今天”），还没完成过的写“暂无完成记录”（灰色）；结束重复以后仍然显示。完成过的，点这一行打开“完成记录”弹窗：最近的在前，每行左边是完成的日子（“11月8日 周六”，今天、昨天照写），右边是截止在哪天和差了几天（“截止11月5日 · 晚 3 天”，同一天的写“按时”，早的写“提前 2 天”），并排放不下时换到下一行，靠右；有记录以前的完成在最后写“更早的 3 次没有记录”。底部“删除事项”上面多一行主色文字的“结束重复并完成”，再上面一行是主色文字的“跳过这一次”（已是最后一次的没有），提示条写“已跳过，下一次：下周一”，有解锁的接着写“解锁了“××””，解锁的事项同样闪一下，附“撤销”。完成过的，再上面一行是主色文字的“撤销上一次完成”：撤销最近一次完成所在的批次，截止和开始日期、次数和最近的日期一起改回去（之后又改过的部分保留，同[撤销](design.md#改动记录和撤销)），提示条写“已撤销上一次完成”，附“撤销”；可以接着点，一次往前撤一次。本机最近的改动里找不到那次完成时不显示，比如完成得太久了，或者这台设备的数据是在那之后才下载的；那次完成和别的事项一起做的（批量完成），或者和新建这一项是同一次改动的，也不显示，免得连带撤掉别的。做完[重复到](design.md#重复)的最后一次而完成的，这一行仍在，撤销后回到重复中；结束重复并完成、或者重新打开以后不再重复的，没有这一行：撤掉更早的一次，事项也不会回到重复中。
- 弹窗底部的按钮一样高（40，胶囊形），靠右排：主操作是实心按钮，其他操作是浅色底的色调按钮，“取消”是文字按钮；删除、清除这类单独放在最左边，用红色文字，和其他按钮隔开。
- 对话框：Material 3 样式，用于确认会丢失或改变状态的操作（删除依赖、前置没完成或没到开始时间时标为完成）。
- 提示条：反色背景，可以带一个操作（多数是“撤销”）。只告知结果的 3 秒后消失，免得挡住后面的操作；带操作的 5 秒后消失（同步来的改动，自己的 agent 的和别人的，以及新版本的提醒 8 秒）。带“撤销”的，在用户接着又做了一个改动时立即消失：它要撤销的已经不是最后一次改动；点别处、滚动不算。开着弹窗时也能点，点它不会关掉弹窗（如共享面板里添加了人，接着撤销）。最右边是“×”，点了立即关掉；手机上也可以像通知一样左右滑走：跟着手指移动、变淡，松手时滑过三分之一宽或快速一甩就滑出去关掉，否则弹回，滑动不算点了上面的按钮。

### 附件

[附件](design.md#附件)在详情里描述下面一组：

- 标题“附件”。图片排成方形缩略图，手机上一行 3 个，电脑上随详情栏的宽度每个至少 80（默认宽度一行 4 个），圆角 10，间隔 6；其他文件一行一个：类型图标、文件名（太长时省略）、大小（“320 KB”“1.2 MB”）。最后一行是主色的“添加附件”：手机上弹出菜单“拍照”“相册”“文件”，电脑上直接打开选文件的窗口，可以多选。
- 刚加的附件马上显示。还没上传完时，缩略图右下角叠一个小图标：在传是转圈，离线时是带斜线的云；文件行的大小换成“等待上传”。上传被拒绝（比如超过服务器或反向代理允许的大小，重试也不会成功）时，提示条写明哪个、为什么，附件随之去掉；AI 整理请求带的附件被拒绝时，整个请求撤回，原文和附件都放回快速添加栏，传不上去的那个右上角标红，点按显示原因，去掉后可以重新提交。
- 别的设备加的，第一次显示时下载，期间缩略图是浅色底加转圈；离线下载不了时是一个灰色图片图标。这台设备显示不了的图片（格式不支持或文件损坏），缩略图、查看器和待添加的附件里也是这个图标。
- 粘贴：详情开着、焦点不在输入框里时按 ⌘V（Ctrl + V），粘贴的文件加到这一项；在描述的编辑框里粘贴，加为附件的同时在光标处插入引用，没有文件时照常粘贴文字。电脑上把文件拖到详情上也一样，拖到描述的编辑框里时同样插入引用；拖动时详情上盖一层主色虚线框，中间写“松开添加附件”。
- 点缩略图打开图片查看器。点文件行打开文件：App 里交给系统默认的应用（没有能打开的时提示“没有能打开这种文件的应用”），浏览器里图片、PDF 和文本在新标签页打开（文本一律按纯文本显示），其他下载，见[网页端](web.md#附件)。
- 文件行右边的“…”和右键菜单（缩略图也有右键菜单）：在描述中引用、重命名、拷贝图片、用默认应用打开、保存到…（浏览器里是“下载”）、删除。拷贝图片只有图片有，手机 App 和没有剪贴板接口的浏览器（比如经普通 HTTP 打开的自建服务器）里没有；用默认应用打开只有桌面 App 里的图片有（别的文件点开就是）。删除后提示条附“撤销”。
- 用鼠标时，指针移到缩略图上（或键盘焦点在上面），右上角出现“在描述中引用”和“删除”两个小圆按钮（28，半透明黑底、白色图标）。
- 重命名：弹窗，输入框里预先选中扩展名前面的部分，回车保存；不能为空，不能含 `/` 和 `\`。
- 在描述中引用：正在编辑描述时插在光标处，否则接在描述最后（另起一行），提示条写“已在描述中引用”。
- 拷贝图片：转成 PNG 放进剪贴板，可以粘贴到别的应用，提示条写“已拷贝图片”。

图片查看器：

- 全屏黑底，图片适应窗口、居中。滚轮（包括触控板双指上下滑）以指针为中心缩放（指针在图片外时以图片上离它最近的点为中心），双指捏合、触控板捏合也能缩放，电脑上还可以按 + − 缩放、按 0 回到适应窗口；放大后可以拖动；双击（触屏上双击）在适应窗口和原大小之间切换。
- 点图片外面的黑色区域关闭。没放大时左右滑动切换这一项的其他图片，电脑上用方向键或两侧的 ‹ ›。
- 顶栏：左边是关闭，中间是名称和“2/5”，右边是菜单里的那些操作（在描述中引用、重命名、拷贝图片、用默认应用打开、保存、删除）的图标按钮，各端有哪些和菜单一样；⌘C（Ctrl + C）也是拷贝图片。删除后关闭查看器，提示条附“撤销”。返回键和 Esc 关闭。
- macOS 的 App 里，顶栏左边让出窗口的红黄绿三个按钮，拖顶栏可以移动窗口。
- 打开时淡入，关闭时淡出，和其他浮层一样。

描述里的引用：

- 预览时是一个小标签：高 22，圆角 6，secondary-container 底色，前面是图片或文件图标（14），后面是附件现在的名称（最长 16 个字，多了省略）；点了和点那个附件一样。
- 附件已删除，或者不是这个事项的附件时，变灰、名称划掉，写引用里原来的名称，点了没有反应。

快速添加栏里的附件：

- 在快速添加栏（和展开的 AI 整理编辑页）里粘贴或拖进文件时，输入区上方出现一排待添加的附件：图片是 48 的方形缩略图，其他文件是图标加文件名的小标签，右上角有 × 去掉；放不下时这一排横向滚动。
- 照样要写标题，AI 整理照样要写内容。提交时新事项带上这些附件，AI 整理的请求也带上，见 [AI 整理](ai.md#附件)。
- AI 整理时，模型看不到的图片（没打开“识别图片”，或者超过 5 MB、不是 PNG/JPEG/WebP/GIF、第 10 张以后）缩略图左下角标“AI 无法查看”，点按显示原因；它们只把名称和类型发给模型。
- 待添加的附件和草稿的文字一样，各页一份，切换页面、关掉 App 后都还在。

### 批量操作

一次选中多项事项，完成、移动或删除。

- 进入：
  - 文件夹页（根目录也是）“…”菜单里的“批量操作”。手机的“文件夹”页（根目录）和电脑上根目录的标题旁原来没有“…”，加上，菜单和根目录的右键菜单相同，再加这一项。
  - “已完成”页标题右侧的“批量操作”按钮：这一页没有别的操作，不放菜单。
  - 电脑上按住 Ctrl（Mac 上 ⌘）点按事项，直接进入并选中这一项。
  - 在关系图里选“批量操作”时先切到列表。
- 进入后：
  - 手机顶部栏左边是“×”（退出），中间是“已选 N 项”（一项没选时写“选择事项”），右边是“全选”，都选上以后变成“全不选”。大标题旁的“…”、列表和关系图的切换、搜索框收起。底部栏和快速添加栏换成操作栏：每个操作图标在上、文字在下，一项没选时变灰。
  - 电脑上没有底部栏：中栏顶部标题的位置换成“已选 N 项”、“全选”和操作按钮，最右边是“退出”。
  - 每个事项行右边出现选择框：圆角方框（圆角 5，同描述里的清单框，和圆形的勾选圈区分开），选中时主色实心、白色对勾，整行换成 secondary-container 底色。点行的任何地方都是选中或取消；勾选圈、滑动、拖动、右键菜单和打开详情都停用，打开着的详情收起。
  - 只能选事项：子文件夹行和 AI 整理请求变淡，不能点。文件夹底部折叠的已完成区可以展开，展开后里面的事项也能选。“全选”选中页面上列出的全部事项，折叠着的不算。
  - 电脑上：按住 Shift 点按，选中上一次点的那项到这一项之间的全部；Ctrl（⌘）+ A 全选；Delete 或 Backspace 等于点“删除”；Esc 退出。
  - 离开这一页或按返回都会退出。在别处（其他设备、agent、别的成员）删掉或移走的事项，从选中里去掉。
- 操作：

  | 页面 | 操作 |
  |---|---|
  | 文件夹 | 完成（选中的全是已完成的事项时换成“重新打开”）、移动到…、负责人…（共享的文件夹里）、删除 |
  | 已完成 | 重新打开、删除 |

- 每个操作先确认，确认后作为一次改动提交，提示条附“撤销”，一步撤销全部；做完退出批量操作。对话框里只有 1 项时，“它们”写成“它”。
  - 完成：对话框“将 5 项标为完成？”，按钮“标为完成”。选中的已完成事项不变。有等前置或没到开始时间的，正文写“其中 2 项还在等待”；有重复的，写“重复的 1 项将顺延到下一次”（做的是重复到的最后一次的不算，它直接完成）。和单个完成一样，完成的事项多停 0.9 秒再收起，解锁的事项闪一下。提示条写“已完成 5 项”，有解锁的写“已完成 5 项，解锁了 2 项”。
  - 重新打开：对话框“重新打开 5 项？”，正文“它们的后续可能因此变回等待中。”提示条写“已恢复 5 项”。
  - 移动到：弹出[选文件夹](#弹窗对话框提示条)，选了目标就算确认，不再另弹对话框。移进去的排在最后，依赖不变（移进、移出共享的文件夹时去掉连到外面的，见[共享](#共享)）。提示条写“已将 5 项移至“工作””。
  - 负责人：弹出[选负责人](#共享)，勾上的人替换选中各项原来的负责人，一开始勾着的是选中的各项都有的负责人；点“确定”生效。提示条写“已设置 5 项的负责人”。
  - 删除：对话框“删除 5 项？”，正文“连着它们的依赖一并删除，可撤销。”，按钮是红色的“删除”。提示条写“已删除 5 项”。
- 一次改动最多 1000 个操作：选中超过 1000 项时点操作，提示条写“每次最多处理 1000 项”。

### 拖动

- 文件夹里的事项和子文件夹可以拖：手机上长按（约半秒）拿起一行，电脑上用鼠标按住直接拖，带触屏的电脑用手指时也是长按。各行一样高，文件夹名过长时只显示一行、末尾省略。“接下来”“已完成”和搜索结果不能拖；电脑上拖动时按 Esc 取消。
- 排序：拖到行与行之间，其他行让位。事项拖出依赖允许的范围时弹回，并提示是哪一项挡住了；子文件夹的顺序不受限制，左栏按同样的顺序显示。
- 拖进文件夹：拖着的事项或文件夹停在一个文件夹行上，这一行换成 primary-container 底色，其他行回到原位，拖着的那一行变成半透明，露出下面变色的文件夹；松手就移进去，排在最后，提示条写“已移至“××””，附“撤销”。停在文件夹行中间的一半算“进去”，上下各四分之一算“之间”，用来排序；事项只能进去，不能排进文件夹之间，停在文件夹行上的任何位置都算“进去”。不能拖进它自己和它里面的文件夹：经过时不变色，松手就回到原位。
- 电脑左栏的文件夹树：
  - 文件夹可以拖，拖着的那一行半透明，其他行不动。停在一个文件夹上就移进去；停在两行之间显示一条主色横线，松手就排到横线下面那一行的前面，和它同一层，横线缩进到那一层；拖到树的最下面，排到顶层最后。停在根目录那一行上，移到顶层最后。
  - 拖着停在收起的文件夹上约 0.7 秒，它自动展开。
  - 中栏的事项和子文件夹也能拖到左栏的文件夹（包括根目录和“共享给我”里的）上，移进去。
  - “共享给我”里的文件夹不能拖动排序，也不能拖出去；它们里面的子文件夹照常能拖。

### 共享

规则见[总体设计](design.md#共享)。本机模式没有这些。

- 头像：圆形，显示名的第一个字，surface-highest 底、on-surface-variant 字（主色只表示可做，不用在人身上）。几个叠放时后一个压住前一个的三分之一，外加一圈 group 色的描边分开；悬停提示写显示名。
- 共享的文件夹：图标换成带两个人的文件夹（共享人和成员那里一样）。文件夹页标题栏的右侧（“…”按钮前面）叠放共享人和成员的头像（28），最多 4 个，再多写“+N”，点开共享面板。
- 共享给我：电脑左栏文件夹树下面一组，组名“共享给我”；手机“文件夹”页里“文件夹”一组下面一组。每行是文件夹名，后面用次要文字写共享人（“装修 · Alice”），计数同文件夹树；左栏里可以展开子文件夹。按共享人、再按名字排。别人共享的文件夹的页面，大标题上方写“Alice 共享”；路径（“接下来”、搜索、详情的所在文件夹）写成“Alice 的装修 / 水电”。
- 共享面板：文件夹“…”菜单和右键菜单的“共享…”、标题旁的头像打开它，是弹窗（手机底部面板，电脑 440 宽卡片），标题“共享“装修””。
  - 列表：共享人和成员各一行，头像、显示名、用户名；共享人标“共享人”，自己的名字后面写“（我）”。
  - 共享人看到：顶上是“输入用户名添加”的输入框和“添加”按钮，回车也能添加，立即生效；成员行右侧有“移除”按钮。添加、移除后提示条写“已添加 Bob”“已移除 Bob”，附“撤销”。添加出错时输入框下方写原因：“没有用户“bob””“Bob 已是成员”。
  - 还没有成员时，列表上方写“共享后，成员可以查看和修改这个文件夹里的一切。”；有连到外面的依赖时再写“连到外面的 3 条依赖将去掉。”。
  - 有成员时，共享人看到左下角红色文字的“停止共享”：对话框“停止共享“装修”？”，正文“所有成员将无法查看这个文件夹，事项的负责人一并去掉。”，提示条附“撤销”。
  - 成员看到的列表不能改，左下角是红色文字的“退出共享”：对话框“退出共享“装修”？”，正文“退出后将无法查看这个文件夹，须 Alice 重新添加才能回来。”，按钮是红色的“退出”。正在这个文件夹里时，退出后回到“文件夹”页（电脑上是根目录）。
  - 能共享的文件夹：不是根目录，不在共享的文件夹里，里面也没有共享的文件夹。其他文件夹的菜单里没有“共享…”。
- 负责人：详情里“所在文件夹”下面一行，只在共享的文件夹里有。设了的写名字，几个人时叠放头像、写“Alice、Bob 等 3 人”；没设时灰色的“未指定（所有成员）”。点这一行打开选负责人。
- 选负责人：弹窗，列出共享人和成员（头像、显示名、用户名），每行右侧一个复选框。详情里点一行就生效，不用确认；批量操作里点“确定”才生效。
- 编号：别人共享的文件夹里的事项，详情里的编号写成 `@alice#42`，复制给 agent 就能用。
- 来源：详情底部和改动记录写人的显示名，令牌做的写成“Bob 的 Claude Code”；自己的照旧。
- 移进、移出共享的文件夹时去掉了依赖或负责人的，提示条写明：“已移至“装修”，去掉了 2 条依赖和 1 位负责人”，附“撤销”。
- 别的成员的改动不弹提示条，只有两种和我有关的例外，附“查看”：
  - 有人把我设为负责人：“Alice 将“装灯具”指派给我”，打开详情。
  - 有人完成的事项解锁了我的事项：“Bob 完成了“铺地砖”，解锁了“装灯具””，几项时写“解锁了 3 项”；一项时打开详情，几项时到“接下来”。

### 其他

- 控件都是自己做的，各端一样，不用浏览器自带的下拉框、日期时间框、复选框、校验气泡和悬停提示；只有选文件（恢复备份）用系统的窗口。
- 分段控件（iOS 样式）：列表和关系图切换、描述的预览和编辑切换、外观选择，以及只有两三个选项的设置（思考程度、重复的单位和下一次从哪天算）。
- 下拉选择：选项多的用它（提醒、重复、AI 服务商）。点开是和“…”菜单同样的列表，当前项右边打勾；在设置行上靠右对齐，在输入框样式的格子上靠左对齐。
- 菜单（“…”菜单、右键菜单、下拉选择）的大小跟着指针走：用手指时每项 44 高、15 号字，好点按；主要用鼠标或触控板时（`pointer: fine`）每项 32 高、14 号字、图标 16，和系统的菜单相近。
- 时间选择：顶上是输入框，可以直接输入几点几分，如“9:07”“9.07”“907”，只写几点的是整点（“9”就是 9:00）。手机上弹出数字键盘，用“.”分开时和分。边输入边生效（有的手机的数字键盘没有回车），回车收起；回车时输入不对，框变红。在下面两列里点选后，输入框清空。下面是时和分两列，分钟每 5 分钟一档，原来的和当前的时间不在档上时也列出；点开时两列滚到选中的位置。点小时后再点分钟，点了分钟就收起；没设时间时要先点小时。底部是“不设时间”。
- 数字加减：两边是 − 和 +，到了上下限的那边不可点；中间的数字也能直接输入，超出范围的按上下限算。
- 输入建议：输入框下方弹出候选（如 AI 设置里从接口获取的模型），聚焦时列出全部，输入后按包含的文字筛选；可以用方向键和回车选。
- 复选框：圆角方框，和描述里的清单一样（如整理建议里勾选要采纳的修改）。
- 开关：开着是主色、圆点在右，关着是灰色、圆点在左；用于设置行上只有开和关两种状态的项（如登录时启动），行的说明只写用途，不写状态。
- 表单校验：提交时第一个空着的必填项边框变红，表单下方用红字写“请填写××”；服务端的校验错误同样标在对应的项上。
- 输入的文字：提交时去掉看不见的控制字符（有的聊天软件复制出来的文字里有，比如 Android 上的 QQ 用它们代替表情），换行和制表符除外；标题、名称这类单行的，制表符换成空格。
- 悬停提示：只有图标的按钮，用鼠标悬停约半秒后在旁边显示说明，反色小气泡（和提示条同色）；手指点按不显示。说明就是按钮的无障碍名称。
- 筛选标签（Material 3 样式）：显示已完成、包含子文件夹。
- 快速添加栏：左边是有底色的输入区（和搜索框同色），右边依次是 ✦（切换 AI 整理）、目标文件夹（只在“接下来”里，默认根目录，名字过长时省略）和发送按钮；发送按钮两种模式都有，没有内容时不可用，切换模式时右边的按钮不移动。输入区随内容增高，最多 5 行，再多就在框内滚动；变高时按钮留在底部。占位文字只占一行，放不下时省略。回车添加事项，标题不能换行，粘贴的多行文字合成一行。“接下来”和每个文件夹各有一份草稿：没提交的文字在切换页面、关掉再打开后仍在，提交后清空，退出登录时删除。
- 快速添加栏的 ✦ 按钮切到 [AI 整理](ai.md#添加)：✦ 按钮变为实心，回车换行，用发送按钮提交，电脑上也可以按 Ctrl + Enter（macOS 上 ⌘ + Enter）。设备记住上次用的模式；还没配置模型时，点 ✦ 打开设置里的“AI 整理”。
- 展开编辑：AI 整理的内容超过 3 行时，快速添加栏右上方出现展开按钮。手机上打开全屏的编辑页，电脑上打开居中的大窗口：标题“AI 整理”，右上角是收起按钮，下面是填满空间的输入区，右下角是目标文件夹（只在“接下来”里）和发送按钮。编辑页和快速添加栏是同一份草稿，收起后文字留在栏里；发送后关闭编辑页。按键规则和栏里一样。
- AI 整理请求行：在所在文件夹的事项列表顶部，“接下来”顶部单独一组“AI 整理”（带文件夹路径）。左侧是状态图标（等待 ✦ 灰色、整理中转圈、失败为红色感叹号），标题是原文第一行，下面一行是状态，失败时是红色的原因，右侧有“重试”。点开是原文和状态，失败的可以改原文后重试或按原文添加；右键菜单有重试、按原文添加、删除。
- 设置首页的“AI 整理”一行显示所用模型和保存位置，点开是模型配置，下面是[说明](ai.md#说明)。
- 描述里的清单是圆角方框，和事项的圆形勾选框区分开；可以直接点选。
- 图标：24 网格、1.8 线宽、圆头圆角的线性图标。正式版用 Lucide，缺的自己按同样规格画。

## 产品图标

- 图形是一段清单：左边一条轨道串起三项，从上到下是已完成（实心圆点，对勾镂空）、可做（圆环）、等待中（虚线圆环），右边各有一条标题，画法和 App 里的事项状态一致。
- 底板是圆角方块，从左上 `#2E8E6C` 渐变到右下 `#14563F`。图形是白色；轨道、等待中的圆环和它的标题用 `#A6F2D1`；已完成的标题是半透明的白色。
- 单色的场合（macOS 菜单栏的模板图，Android 的通知小图标和主题图标）整个图形只用一种颜色，浅色部分降低不透明度。
- 图标文件都由 `apps/web/scripts/icons.js` 生成：网页的 `icon.svg`（也是浏览器标签页图标和左栏、登录页的品牌标）和各尺寸 PNG，Android 自适应图标的背景、前景、单色三层和通知小图标，iOS 的 1024 方形图标和启动画面的标志，macOS 的 `icon.icns`、各尺寸 PNG 和菜单栏图标，Windows 的 `icon.ico`（也是托盘图标）。改图形只改这个脚本，然后在 `apps/web` 下运行 `node scripts/icons.js`；脚本要用 `rsvg-convert`（librsvg）和 macOS 自带的 `iconutil`。

## 交互细节

- 完成一项：勾选框弹一下；这一项在原位多停留 0.9 秒，再用 0.3 秒收起，下面的行随之上移（文件夹里[保留](#设置)了最近完成的 N 项时，它划掉后留在原处，到时收起的是第 N+1 近完成的那一项，不到 N+1 项就都不收起）；收起期间轨道淡出，排好后按新的连线淡入；它解锁的事项闪一下 primary-container 底色（1.6 秒），提示条写“解锁了‘××’”，并附“撤销”。恢复成待办时提示条写“已恢复‘××’”，同样附“撤销”。重复的事项勾选框同样弹一下，但不划掉、不收起，截止时间随即换成下一次（“接下来”里这一行随之移到新的位置）；顺延到明天以后的，前面出现“今天已完成”；它[解锁](design.md#重复)的事项同样闪一下，提示条写“下一次：××”，有解锁的写“下一次：××，解锁了‘××’”，附“撤销”。结束重复并完成，和做完[重复到](design.md#重复)的最后一次，都和普通的完成一样划掉、收起；最后一次的提示条写“‘××’已完成最后一次”，有解锁的写“已完成最后一次，解锁了‘××’”，附“撤销”，让人知道它为什么没有顺延。
- 前置未完成或没到开始时间时勾选：先弹对话框确认，写明在等什么（“还有 2 项前置未完成”“要到 11 月 14 日 09:30 才开始”）。
- 列表行右滑超过 90px 完成，左滑超过 90px 删除，删除后可撤销。
- 文件夹里的事项和子文件夹可以拖动排序，也能拖进别的文件夹，见[拖动](#拖动)。
- 右键菜单（电脑上用鼠标时，Mac 上按住 Control 点按也算右键；手指或触控笔的长按留给拖动，带触屏的电脑也一样）：事项有“打开”“标为完成”或“重新打开”“移动到…”“删除”，重复的事项在“标为完成”后面多“跳过这一次”（已是最后一次的没有）和“结束重复并完成”两项；文件夹（左栏和文件夹列表里）和它的“…”菜单相同，即“新建子文件夹”“AI 整理事项”“AI 说明”“共享…”（能共享的文件夹，见[共享](#共享)）“重命名”“颜色和图标…”“复制…”“移动到…”“删除文件夹”（需确认），根目录只有“新建文件夹”“AI 整理事项”和“AI 说明”；别人共享给我的文件夹只有“新建子文件夹”“AI 整理事项”“AI 说明”“共享…”“复制…”和“退出共享”。其他地方右键没有菜单；输入框、选中的文字和链接保留浏览器自己的菜单，用来复制粘贴。
- 自己的 agent 批量改动后：提示条写“Claude Code 在‘求职’中添加了 4 项”，附“撤销”。别的成员的改动不弹提示条，只有两种和我有关的例外，见[共享](#共享)。
- 鼠标指针：能点的元素都显示手型；关系图画布显示抓手，拖动时变成握拳；弹窗后面的遮罩显示默认箭头。
- 不显示原生滚动条。
- 浮层（弹窗、对话框、底部面板、AI 输入页、提示条、菜单）进场时减速停下，关闭时沿原路加速离开，退场比进场短：手机上的面板约 0.26 秒，电脑上的卡片、对话框和提示条约 0.16 秒，菜单 0.12 秒。新的提示条直接盖在正在淡出的旧提示条上。
- 状态变化用过渡，不跳变：
  - 展开和收起（文件夹底部的“已完成”、电脑左栏的文件夹树）：0.25 秒展开、0.2 秒收起，高度和透明度一起变；打开页面时已经展开的直接显示。
  - 悬停、按下和选中的底色（列表行、左栏、菜单项、图标按钮、日期和时间）0.15 秒渐变，鼠标从一行移到另一行时，前一行淡出、后一行淡入。
  - 分段控件的选中块滑到新选的一项（0.25 秒）。
  - 批量操作：选择框缩放淡入，勾上和取消时渐变；不能选的行渐渐变淡（0.2 秒）。
  - Android 的[弹窗提醒](android.md#弹窗提醒)是原生界面，同样处理：换成推迟的选项、自定义时间或下一条提醒时，旧内容淡出、新内容淡入，卡片高度随之变化；完成时勾选圈和标题渐变；分段控件的颜色渐变。小组件由系统绘制，不做动画。
- 系统开启“减弱动态效果”时，去掉动画和过渡。
- 需要详细说明的地方附上[官网](https://juniexd.github.io/NextTodo/)教程的链接，在浏览器里打开（`ui/help.tsx`）：登录页的“了解两种用法”和服务器地址旁的“如何部署”，AI 整理设置的“如何获取 API 密钥”，本机模式卡片的“说明”，令牌生成后的命令行安装说明，设置“关于”里的“使用教程”。链接用主色加下划线，和正文分得清。

## 文案

- 简明书面：用“暂无、无法、失败、已、将、须”这类书面说法，句子尽量短；不用“没能、不对、马上、好了”这类口语，不对用户称“你”。界面、提示、错误信息、小组件、通知、命令行和工具输出都按这个风格。
- 用用户能懂的话，不用系统内部的叫法；同一个操作从按钮到提示用同一个词（“撤销”→“已撤销”）。
- 空状态说明下一步能做什么，比如“暂无事项。可在下方输入，或让 agent 拆分计划。”
- 出错时说清发生了什么、怎么处理，不道歉，不含糊，比如“保存失败：{原因}”“无法连接服务器，请检查网络后重试”。
- 错误信息统一写成“{操作}失败：{原因}”；原因说不清时写“{操作}失败，请稍后重试”。可以重试的，统一说“请稍后重试”。
- 系统和第三方的原文（英文报错、错误码、`os error`、堆栈）不直接显示：原生部分和服务端先换成用户能懂的原因，比如“没有权限访问这个位置”“存储空间不足”，原文记进日志，网页的记进控制台。原生部分写好的中文提示已经说了是哪一步，原样显示；服务端返回的原因跟在“{操作}失败：”后面，表单里的错误紧挨着输入框，直接写原因。模型接口返回的错误例外：先说明状态码的含义，再在括号里附上原话，见 [AI 整理](ai.md#模型配置)。
- 页面崩溃时显示“页面出错”和“重新加载”，错误原文收在下面的“错误详情”里，供反馈问题时使用。
- 中文标点，中文与英文、数字之间留空格。
