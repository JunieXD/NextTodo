# 下载和安装

NextTodo 有 Android、iOS、macOS 和 Windows App。连接自己的服务器时，也可以在浏览器里使用网页版。下面的下载链接总是最新版。

## Android

要求 Android 8.0 及以上。

1. 用手机浏览器打开 [NextTodo-android.apk](https://github.com/JunieXD/NextTodo/releases/latest/download/NextTodo-android.apk)，下载安装包。
2. 下载完成后点开它。第一次安装从浏览器下载的应用时，系统会提示不允许安装未知来源的应用：点击“设置”，打开“允许来自此来源的应用”，返回后继续安装。各品牌手机的叫法略有不同。
3. 打开 NextTodo，[选择用法](./#modes)。

要按时收到提醒，打开 App 的“设置 → 提醒”，按提示允许“通知”和“准时提醒”；想换铃声和振动，点同一页“铃声和振动”一行的“打开设置”。小米、红米等使用澎湃 OS 的手机，还要在“设置 → 系统”里点“自启动和省电”一行的“打开设置”，允许自启动，并把省电策略设为“无限制”；要让提醒在屏幕顶部弹出，再进“通知管理”，在“提醒”里打开“悬浮通知”。“设置 → 提醒”里的“弹窗提醒”打开后，到点在屏幕底部弹出卡片，需要允许“显示在其他应用上层”（澎湃 OS 叫“悬浮窗”）。

桌面小组件：长按手机桌面的空白处，选择“小组件”，找到 NextTodo，拖到桌面上。一共有五个：

- **接下来**：列出可做的事项，可以直接勾选完成；点右上角的 + 弹出添加框，键盘随即弹出。没联网时勾选先存下，联网后自动补上。默认是 4×2 的大小，可以拖动边框调整，最小 1 格：不到 3 格高时每项占一行、不显示文件夹，以便多放几项；更高时每项两行，第二行写着文件夹。
- **日程**：按天列出今天起 7 天截止的事项，最前面是已逾期的；重复的事项以后的每一次也列在那天，写着“以后的一次”。它只用来看：点一项打开详情，点标题“日程”打开日历。
- **一周**：选一天，看那天截止的事项，点圆圈即可完成，点 + 添加到选中的那天。
- **时间轴**：按钟点看一周截止的事项，点空着的格子添加到那个钟点。
- **月历**：按月看每天截止的事项。

“接下来”和“日程”都能缩到 1 格，太小时收起勾选圆圈和按钮。背景颜色、不透明度、文字颜色和大小、标题栏，以及“一周”从今天起还是从周一起，在 App 的“设置 → 小组件”里调。

不打开 App 也能随手记一条：长按 NextTodo 的图标选“快速添加”，或者在控制中心加上“快速添加”开关，屏幕底部就弹出添加框。在别的 App 里分享文字、图片或文件时选“NextTodo”，也是在这里添加。

写进系统日历：在“设置 → 系统”里打开“写进系统日历”并允许读写日历，带截止时间的未完成事项就会出现在手机的日历里，只有日期的是全天日程。默认写进一个只在这台手机上的“NextTodo”日历；也可以在同一行换成 Google、小米等账号的日历，那样日程会随账号同步到云端。日程跟着事项更新，完成或删掉的会从日历里去掉。“NextTodo”日历是只读的；写进账号日历的，在日历里改了或删了，下次会按事项写回来。日程不带提醒，提醒仍由 NextTodo 发出。退出登录或改用服务器时，写进去的日程会删掉。

## iOS

要求 iOS 16.4 及以上（iPhone 8 及以后的机型）。

NextTodo 不上架 App Store，用 [SideStore](https://sidestore.io) 安装：它用你自己的 Apple ID 给 App 签名，不用花钱，也不用越狱。

1. 装好 SideStore：按 SideStore 官网的[安装指南](https://docs.sidestore.io/docs/installation/prerequisites)操作，需要用电脑装一次，同时会装上它要用的 LocalDevVPN。之后在 SideStore 里安装、更新和续签 App 时，都要先打开 LocalDevVPN。
2. 在 iPhone 上打开 SideStore，进“Sources”（软件源）页，点 +，填入下面的地址并添加：

   ```
   https://github.com/JunieXD/NextTodo/releases/latest/download/sidestore.json
   ```

3. 在这个软件源里找到 NextTodo，点击安装。
4. 打开 NextTodo，[选择用法](./#modes)。

用免费 Apple ID 签名的 App 7 天后过期，过期后打不开，但数据还在。SideStore 会在后台自动续签；隔几天打开一次 LocalDevVPN 和 SideStore，在“My Apps”页点“Refresh All”最稳妥。免费 Apple ID 同时只能装 3 个这样签名的 App，SideStore 自己算一个。

提醒：第一次设了提醒后，App 会请求发送通知，点“允许”。到点即使没打开 App 也会弹出通知；长按通知可以直接“完成”，或推迟 15 分钟、1 小时、3 小时。点了“不允许”的，到 App 的“设置 → 提醒”里点“允许”，在打开的系统设置里打开“允许通知”。

## macOS

要求 macOS 14 及以上。

1. 下载安装包，双击打开：
   - Apple 芯片（M1 及以后）：[NextTodo-macos-arm64.dmg](https://github.com/JunieXD/NextTodo/releases/latest/download/NextTodo-macos-arm64.dmg)
   - Intel 芯片：[NextTodo-macos-x64.dmg](https://github.com/JunieXD/NextTodo/releases/latest/download/NextTodo-macos-x64.dmg)

   不知道是哪种的，点屏幕左上角的苹果菜单 → “关于本机”：有“芯片”一行、写着 Apple M1 这类的是 Apple 芯片，有“处理器”一行、写着 Intel 的是 Intel 芯片。
2. 把窗口里的 NextTodo 拖进“应用程序”文件夹。不要直接在这个窗口里打开它，否则以后无法安装命令行。
3. 打开“应用程序”文件夹，双击 NextTodo。第一次打开时，系统会提示无法验证开发者：
   1. 点击“完成”关掉提示。
   2. 打开“系统设置 → 隐私与安全性”，在页面下方找到关于 NextTodo 的提示，点击“仍要打开”，按提示输入登录密码。
   3. 之后可以正常打开，不会再提示。

   出现提示是因为 NextTodo 没有向苹果付费做签名公证，不代表它有问题。

4. [选择用法](./#modes)。

关掉窗口后，NextTodo 仍在菜单栏里，继续同步和提醒。点菜单栏的图标弹出小窗：看接下来要做的事，点顶上的名字可以换成“一周”“时间轴”或某个文件夹；勾选完成、快速添加，不用打开主窗口；右键图标选“退出”才会退出。还可以在“设置 → 系统”里设一个小窗快捷键，在任何应用里按下就能弹出小窗。要开机时自动运行，在“设置 → 系统”里开启“登录时启动”。觉得字太大或太小，在“设置 → 外观”里给主窗口和小窗分别选“界面大小”。想让“接下来”一直摆在桌面上，在“设置 → 小组件”里打开“在桌面上显示”，桌面小组件同样能勾选完成和快速添加，拖顶上一行移动、拖边缘改大小。

## Windows

要求 Windows 10 或 11，x64。

1. 下载 [NextTodo-windows-x64-setup.exe](https://github.com/JunieXD/NextTodo/releases/latest/download/NextTodo-windows-x64-setup.exe)，双击运行。
2. 出现“Windows 已保护你的电脑”时，点击“更多信息”，再点击“仍要运行”。原因和 macOS 一样，安装程序没有付费签名。
3. 按提示完成安装。安装程序只装给当前用户，不需要管理员权限；系统缺少 WebView2 时会自动下载。
4. [选择用法](./#modes)。

关掉窗口后，NextTodo 仍在任务栏右下角的托盘里，继续同步和提醒。点托盘图标弹出小窗，用法和 macOS 一样；右键托盘图标选“退出”才会退出。小窗快捷键同样在“设置 → 系统”里设。要开机时自动运行，在“设置 → 系统”里开启“登录时启动”。界面大小同样在“设置 → 外观”里调，桌面小组件同样在“设置 → 小组件”里打开。

## 网页版

只在连接服务器时可用：用浏览器打开服务器的地址，登录即可。

网页版可以安装成独立的窗口：Chrome 和 Edge 点地址栏右侧的“安装”图标；iPhone 和 iPad 的 Safari 点“分享 → 添加到主屏幕”。网页版不弹出提醒，需要提醒的请用 App。

## 更新

Android 和电脑上的 App 会自己检查更新：

- **连接服务器时**：App 从服务器获取更新，服务器升级后随之更新。Android 平时只更新界面部分，下次打开时生效，需要换安装包时会提示；电脑上在后台下载，提示“重启”后生效。
- **在本机使用时**：App 从 GitHub 获取更新，有新版本时会提示：Android 每个新版本都要点“下载安装”换安装包，电脑上同样在后台下载、提示“重启”。

iOS 的 App 不能自己更新：有新版本时会提示，到 SideStore 的“My Apps”页更新。

版本号在“设置 → 关于”里查看。点按“App 版本”可以立即检查更新，下方会显示检查结果；连不上服务器或 GitHub 时也会写明。连接服务器的 Android 很少需要换安装包，所以安装包的版本常常比 App 版本旧，两者不同时“App 版本”下方另写着安装包的版本。
