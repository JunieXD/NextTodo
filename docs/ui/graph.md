# 关系图

- 布局：正式版用 ELK Layered，在实现时用真实数据对比几组参数调到最好。要求：连线不穿过节点，交叉尽量少，链条尽量直，可做的事项排在第一层。手机从上到下排，电脑从左到右排。
- 节点：可做用 primary-container 填充；等待中是白底描边；已完成和已放弃灰底划掉；文件夹外的事项虚线框、半透明，上方标注所在文件夹。标题下面一行次要信息只放得下一样，依次取第一个有的：还没到开始时间的“11 月 20 日 09:30 开始”（连线看不出它在等什么；开始不晚于截止，这时截止也不会已经逾期）、截止时间、等待中的“等 N 项”。设了负责人的，这一行右端叠放负责人的头像（16），最多 2 个，再多写“+N”。手机节点宽 104–146（按屏幕宽度自适应），电脑 184，高 60。
- 选中节点外加主色描边；不在它前后链上的节点降到 28% 不透明，链上的连线变主色并加粗。
- 画布背景是随平移和缩放移动的网点。
- 手势：单指或鼠标拖动平移；双指捏合缩放（以两指中点为中心，同时可以平移）；触控板双指滑动平移，捏合或 Ctrl + 滚轮缩放。缩放范围 0.35–2.5。拖动之后不触发点击。
- 连线：点“连线”进入连线状态，按钮变成“完成”。依次点前置和后续连上一条，随即回到选前置，可以接着连下一条，直到点“完成”、按 Android 的返回键或 Esc 退出（焦点在输入框里时 Esc 归输入框）。顶部提示当前步骤，选中的前置节点有脉冲光圈，再点它就取消选择。连出循环时拒绝，并列出环上的事项。
- 点连线弹出删除确认。
- 快速添加栏和列表的一样，在同一个位置（手机上浮在底部栏上方，电脑上在中栏标题下方），和列表共用这个文件夹的草稿。加上的事项画进图里（没有连线，在第一层），画布平移到能看见它，节点闪一下（同[解锁的闪烁](../ui.md#交互细节)），不打开详情，好接着加下一项或点“连线”；AI 整理的请求整理完以后同样画进图里，不平移。连线状态和批量操作时这一栏藏起来，写了一半的留着。手机上“连线”按钮在这一栏的正上方，栏变高时跟着往上，这一栏藏起来时落到它的位置；提示条在两者上方，不挡按钮。画布平移时，新节点要露在栏和按钮上面。
