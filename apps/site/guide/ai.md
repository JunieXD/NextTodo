# AI 整理

把随手写下的一大段话交给 AI，整理成一条或几条事项：标题、描述、截止时间、先后关系，以及原文说了的重复（如“每周一开例会”）都会填好，原文的信息不丢；还可以带上截图、照片一起整理。也可以让 AI 整理一个文件夹里已有的事项。

NextTodo 不提供 AI，用的是自己在大模型服务商那里申请的 API 密钥，费用由服务商按用量收取。

## 1. 获取 API 密钥 {#key}

API 密钥是一串字符（通常以 `sk-` 开头），是在服务商那里使用模型的凭证，不要告诉别人。任选一家服务商：

| 服务商 | 控制台 | 说明 |
|---|---|---|
| DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) | 国内可直接使用 |
| 通义千问 | [阿里云百炼](https://bailian.console.aliyun.com) | 国内可直接使用 |
| OpenAI | [platform.openai.com](https://platform.openai.com) | 需要境外的支付方式 |

步骤大致相同：

1. 注册并登录服务商的控制台，按要求完成实名认证或充值。
2. 在控制台的“API Key”页面创建一个密钥。
3. 立即复制并妥善保存：多数服务商只在创建时显示一次完整的密钥。

也可以用其他兼容 OpenAI 接口的服务商，选择“自定义”，填写它的接口地址和模型名称。

### 用自己电脑上的模型 {#ollama}

Ollama、LM Studio 这类在自己电脑上运行的模型也兼容 OpenAI 接口。服务商选“自定义”：

- **接口地址**：Ollama 是 `http://<地址>:11434/v1`，LM Studio 是 `http://<地址>:1234/v1`。
- **API 密钥**：它们不检查，随便填一个，比如 `ollama`。
- **模型**：点“从接口获取列表”，选已经下载好的模型。

地址怎么填，要看是谁去访问模型：

- **在本机使用**：App 自己访问模型。模型在同一台电脑上就填 `127.0.0.1`，在局域网里的另一台电脑上就填它的局域网 IP。Ollama 默认只接受本机的连接，要在那台电脑上设环境变量 `OLLAMA_HOST`，值是它的局域网 IP（比如 `192.168.1.10`）。Ollama 没有密码，不要让它监听公网地址。
- **连接服务器**：是服务器去访问模型，访问不到你手机或电脑上的模型。模型要和服务器在同一台机器或同一个局域网里，地址按服务器那边填；还要管理员先放行，见[用内网里的模型](./server#lan-model)。

小模型不一定按要求输出，整理前先点“测试”试试。

## 2. 在 NextTodo 里配置

1. 打开“设置 → AI 整理”。
2. 选择服务商，接口地址和模型会自动填好。
3. 把 API 密钥粘贴到“API 密钥”一栏。
4. 点“测试”，显示成功就说明配置正确；失败时会显示服务商返回的原因，比如密钥错误或余额不足。测试时还会试一下模型能不能看懂图片，按结果打开或关闭“识别图片”，见[附件和图片](#images)。
5. 点“保存”。

在本机使用时，配置只保存在这台设备上，没有其他选项。连接服务器时，保存前还要选择“保存位置”：

| 保存位置 | 密钥存在 | 什么时候整理 |
|---|---|---|
| 仅本机 | 这台设备上 | 这台设备联网时 |
| 同步到服务器 | 服务器上，加密保存 | 提交后设备可以离线，服务器自己整理 |

选“同步到服务器”需要服务器设置过加密密钥，见[部署服务器](./server#ai)。

“思考程度”越高，整理得越仔细，也越慢、费用越高。

## 3. 把一段话整理成事项

1. 点添加框里的 ✦，切换到 AI 整理。
2. 写下要做的事，想到什么写什么，可以很长。这时回车是换行。
3. 点发送按钮提交；电脑上也可以按 Ctrl + Enter（macOS 上 ⌘ + Enter）。

提交后不用等：列表顶部出现一行“整理中”，整理好后变成事项，提示条写着添加了几项。不满意可以点“撤销”，原文还在，可以改了再试。

整理失败时，那一行会写明原因。点开它可以重试、修改原文后重试，或者“按原文添加”成一个事项。

发给服务商的内容：原文、提交时间、所在文件夹的路径和用到的 [AI 说明](#notes)，以及这个文件夹里未完成事项的编号、标题、截止时间和先后关系（最多 50 项），好让 AI 把新事项接在已有事项后面。在共享的文件夹里，还有共享人和成员的显示名和用户名，好按原文设负责人。带了附件的，还有附件的名称和类型，以及打开“识别图片”时的图片本身。已有事项的描述不发。

### 附件和图片 {#images}

在添加框里粘贴或拖进图片和文件，和原文一起提交。整理好后，附件放到整理出的事项上。

- 模型能看懂图片时（服务商的文档里一般叫“视觉理解”或“多模态”），在“设置 → AI 整理”里打开“识别图片”，图片会随原文一起发给模型，图片里的信息也会整理进事项，比如截图里的会议时间、照片里的清单。点“测试”时会自动判断并设好这个开关。
- 每次最多发 10 张，每张不超过 5 MB，支持 PNG、JPEG、WebP 和 GIF。模型看不到的图片（没打开“识别图片”，或者超出这些限制），在添加框里标着“AI 看不到”，只把名称和类型发给模型。
- 不是图片的文件只发名称和类型，内容不发。

## 4. 整理已有的事项

用自己的话告诉 AI 要对一个文件夹里的事项做什么：改标题和描述、补上或调整先后、改截止时间和重复、标为完成或重新打开、删除、移进子文件夹、新建、调整顺序，在界面上能做的都可以。AI 只提出建议，确认后才会修改。

1. 点文件夹页顶部的“…”按钮（电脑上也可以右键文件夹），选“AI 整理事项”。
2. 写下要求，比如“先订酒店再订机票”“把交报告推迟到下周五”“合并重复的事项”；或者直接用默认的“把标题改清楚，描述改成简洁的书面语，补上漏掉的先后关系。”。回车换行，电脑上按 Ctrl + Enter（Mac 上 ⌘ + Enter）提交。
3. 整理好后，列表顶部显示“N 条建议，待确认”。点开它：
   - 每个事项先写着 AI 的理由，下面每处修改一个勾选框；新建的事项和调整顺序各自一组。
   - 取消勾选不想要的修改，点“应用 N 处”。应用后可以撤销。
   - 不想要这批建议，点“放弃”；想按现在的事项重来，点“重新整理”。

没写具体要求时，AI 只改写标题和描述、补上漏掉的先后；删除、完成、移动这类修改，要你在要求里说了才会提出。

整理时会把这个文件夹里未完成事项的标题、描述、截止时间、提醒、重复和先后关系，最近完成的 20 项的标题，以及子文件夹的路径发给服务商。

## 5. AI 说明 {#notes}

有些要求每次整理都一样，比如“标题以模块名开头”“只说了日期的截止时间定在 18:00”。把它写成 AI 说明，以后在这个文件夹里整理都会照着做，不用每次写进原文或要求里。

- 每个文件夹可以写一段，根目录的就是全局说明。在一个文件夹里整理时（把一段话整理成事项、整理已有的事项都算），从根目录到这个文件夹一路上的说明都会用上；内层文件夹的和外层的不一致时，以内层的为准。
- 说明只对自己有效：在共享的文件夹里，各人写各人的。全局说明对别人共享给你的文件夹也有效。
- 说明只管怎么做，不扩大要做的事：比如说明要求标题用英文，而这次只要求推迟某一项，AI 不会顺手改标题。

在两处编辑，打开的是同一个编辑窗口：

- “设置 → AI 整理”里的“说明”一组：“全局”是根目录的说明，下面列出写了说明的文件夹，点“为文件夹添加说明”选一个文件夹再写。还没配置服务商时也可以先写。
- 文件夹页顶部的“…”按钮（电脑上也可以右键文件夹），选“AI 说明”。

编辑窗口里，上级文件夹的说明先灰色列出，注明“也会用到”。每段最多 2000 字。清空后保存，或者点“清除说明”，就去掉了。连接服务器时，改说明要联网。

写具体、能照着做的要求，比如格式和默认值。AI 默认就按原文的语言写，不用写“用中文”这类说明；内外层的说明尽量不要互相矛盾，矛盾时 AI 有时拿不准。

整理时，用到的说明会和上面列出的内容一起发给服务商。
