# 设置

设置是一个页面：手机上是底部栏的第三页，电脑上点左栏左下角的头像，在中栏打开（详情栏收起），标题和内容合成一栏，最宽 600，在中栏里左右居中。首页按类别分组列出，点一类进入它的子页；地址是 `/settings` 和 `/settings/<类别>`，别处要打开某一类（比如还没配置模型时点 ✦）直接进那一页。

类别按管的是什么分，不按在哪里生效分：只有某个平台才有的设置，放进它所属的类别，只在那个平台上出现。首页右侧只写不点开也值得看到的。

| 类别 | 内容 | 首页右侧 |
|---|---|---|
| 账号（最上面的卡片：头像、显示名、用户名） | 显示名、修改密码、已登录的设备、导出备份和导入备份（见[搬到服务器和搬回本机](../local.md#搬到服务器和搬回本机)）、退出登录 | |
| 本机模式（本机模式下代替账号，见[本机模式](../local.md#界面)） | 说明、借网盘同步、备份、恢复、改用服务器 | |
| 改动记录 | 见[改动记录](history.md) | |
| 隐私锁（网页和桌面 App） | 见[隐私锁](lock.md) | |
| 外观 | 主题（跟随系统、浅色、深色）；[主题色](../ui.md#颜色)；桌面 App 上还有主窗口和小窗各自的[界面大小](../desktop.md#界面大小)；“日历”一组：[时间轴视图](calendar.md)开关、[放假和补班](../design.md#节日和放假)开关，都默认开。都存在各自的设备上 | |
| 列表和添加 | “已完成的事项”一组：保留最近完成的事项，0–20 项（默认 0），文件夹里最近完成的这几项划掉后留在原处（按依赖顺序，轨道照常连着），更早的才收进底部的“已完成”，“接下来”不受影响，存在这台设备上；“快速添加”一组：添加到哪个文件夹，见下面；“AI 整理”一组（手机 App 里没有）：“发送键”一行是分段控件“⌘ + Enter”（默认；苹果设备以外写“Ctrl + Enter”）和“Enter”，下面一行写“Enter 换行，⌘ + Enter 发送”或“Enter 发送，Shift + Enter 换行”，用于快速添加栏的 AI 整理（含展开的编辑页）和“AI 整理事项”，存在这台设备上，各窗口跟着变。两种都可以按 Ctrl + Enter 或 ⌘ + Enter 发送；选 Enter 后单按 Enter 也发送，Shift + Enter 换行，Alt + Enter 不发送；输入法选字时的 Enter 不算 | |
| 提醒 | 默认提醒、隐藏通知内容、每日汇总（后两项只在 App 上，见[提醒](../design.md#提醒)）；Android 上还有“通知”一组：通知、[铃声和振动](../android.md#通知)、准时提醒、[弹窗提醒](../android.md#弹窗提醒)；iOS 上是[通知](../ios.md#设置) | |
| 小组件（Android 和桌面 App） | 小组件的预览、背景颜色、不透明度、文字颜色、标题栏、文字大小和“一周”的日子，见 [Android](../android.md#小组件的设置)；桌面 App 上最上面是“在桌面上显示”开关，没有标题栏和“一周”的日子，见[桌面小组件](../desktop.md#桌面小组件) | |
| 系统（Android 和桌面 App） | 和系统打交道的：Android 上是自启动和省电、[写进系统日历](../android.md#写进系统日历)；桌面上是登录时启动、[小窗快捷键](../desktop.md#小窗快捷键) | |
| AI 整理 | [模型配置](../ai.md#模型配置) | 模型和保存位置 |
| agent 接入（本机模式下只在桌面 App 上有） | 令牌；桌面 App 还有命令行 | |
| 服务器（管理员） | “版本”一组：服务器的版本和升级（见[总体设计](../design.md#部署)）；“邀请注册”一组：邀请码、生成邀请码；“附件”一组：压缩图片，见下面 | 能升级时写“可升级” |
| 附件（本机模式下代替服务器） | 压缩图片，见下面 | |
| 关于 | 版本和更新、[更新日志](../design.md#更新日志)；不是管理员的，App 比服务器新时有“服务器版本”一行（见 [App 更新](../design.md#app-更新)）；QQ 群：点群号复制，“加入”在浏览器里打开加群链接（在手机上转到 QQ）；GitHub：下面一行写“开源项目，欢迎 Star 支持”，“打开”在浏览器里打开代码仓库；使用教程 | 有新版本时写“有新版本” |

- 首页分组：账号（或本机模式）、改动记录、隐私锁；外观、列表和添加、提醒、小组件、系统；AI 整理、agent 接入；服务器（或附件）；关于。只列这台设备上、这个用户能用的，一项都没有的组不显示。
- 内容多的子页不再分第二层，在同一页里用组标题分开：常用的在前，只有某个平台才有的组在后。
- “快速添加”一组：“添加到”是分段控件“上次选的”（默认）、“固定的”。点“固定的”先[选文件夹](dialogs.md)，没选就还是“上次选的”；选好后下面多一行“文件夹”，右边写文件夹名，点开再换；那个文件夹删了或退出了共享时写“已不在”。下面小字说明“接下来”和日历的快速添加栏放进哪里。按用户存在这台设备上，见[快速添加的目标文件夹](../ui.md#其他)。
- 压缩图片：开关，下面一行说明“上传前将 JPEG 照片缩小到长边 2560 像素以内，并去除拍摄地点等信息。对所有用户生效。”，见[附件](../design.md#附件)。
- 默认提醒在“提醒”最上面一组，两行“有时间的事项”“只有日期的事项”，右边写选了的提醒，同详情里[“提醒”一行](dialogs.md)的写法，没选的写“不提醒”；点开是同样的多选菜单（只有“截止”一组），最下面也是“自定义…”，选了弹出“自定义提醒”弹窗，内容和按钮同按截止时间的那一页，没有分段控件：有时间的事项只能加提前多久的（按日子的，比如当天 09:00，遇到当天更早截止的事项就会在截止以后才响），只有日期的事项按日子加。每行最多 100 个，再多时提示“提醒最多 100 个”，不保存。下面一组是“隐藏通知内容”开关，小字写“通知里不显示事项的标题和文件夹”。再下面一组是“每日汇总”开关，小字写“每天定时通知今天截止和已逾期的未完成事项”；打开后下面多一行“时间”，右边写时间，点开同截止时间弹窗里的时间选择，没有“不设时间”。
- 子页从右侧滑入，返回时反向，同进入文件夹；返回首页用主色的“‹ 设置”，手机上在顶部栏，电脑上在标题上方。修改密码、生成令牌和令牌生成后的接入写法是弹窗。AI 整理的配置保存或清除后，回到打开它之前的页面。
- 打开事项（点提醒、小组件里的事项）或快速添加时，在设置页的先回到“接下来”。
