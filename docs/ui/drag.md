# 拖动

- 文件夹里的事项和子文件夹可以拖：手机上长按（约半秒）拿起一行，电脑上用鼠标按住直接拖，带触屏的电脑用手指时也是长按。各行一样高，文件夹名过长时只显示一行、末尾省略。“接下来”“已完成”和搜索结果不能拖；电脑上拖动时按 Esc 取消。
- 排序：拖到行与行之间，其他行让位，排成松手后的样子。事项只停在[同一层](../design.md#排序)各串之间，跟着它的那一串排到它后面；落回原处的不算改动。拖出这个范围时弹回，并提示它跟在哪一项后面；子文件夹的顺序不受限制，左栏按同样的顺序显示。
- 拖进文件夹：拖着的事项或文件夹停在一个文件夹行上，这一行换成 primary-container 底色，其他行回到原位，拖着的那一行变成半透明，露出下面变色的文件夹；松手就移进去，排在最后，提示条写“已移至“××””，附“撤销”。停在文件夹行中间的一半算“进去”，上下各四分之一算“之间”，用来排序；事项只能进去，不能排进文件夹之间，停在文件夹行上的任何位置都算“进去”。不能拖进它自己和它里面的文件夹：经过时不变色，松手就回到原位。
- 电脑左栏的文件夹树：
  - 文件夹可以拖，拖着的那一行半透明，其他行不动。停在一个文件夹上就移进去；停在两行之间显示一条主色横线，松手就排到横线下面那一行的前面，和它同一层，横线缩进到那一层；拖到树的最下面，排到顶层最后。停在根目录那一行上，移到顶层最后。
  - 拖着停在收起的文件夹上约 0.7 秒，它自动展开。
  - 中栏的事项和子文件夹也能拖到左栏的文件夹（包括根目录和“共享给我”里的）上，移进去。
  - “共享给我”里的文件夹不能拖动排序，也不能拖出去；它们里面的子文件夹照常能拖。
