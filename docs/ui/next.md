# “接下来”的筛选和后续

## “接下来”的文件夹筛选

[只看某些文件夹](../design.md#接下来)里可做的事项。

- 入口：标题行右边的筛选按钮，和那里的图标按钮放在一起：电脑上在标题右边，手机上在“已完成”左边，菜单栏小窗在“在主窗口打开”左边。不筛选时只是一个灰色的筛选图标；筛选时变成浅色底（secondary-container）的小胶囊，筛选图标后面写选中的名字：一个写它的名字，两个写“工作、学习”，更多写“3 个文件夹”，太长时省略。悬停提示“筛选文件夹”，筛选时后面带上选中的全部名字。
- 点开是弹窗“筛选文件夹”，和 Android 设置里[写进系统日历](../android.md#写进系统日历)的“写入的文件夹”是同一个：根目录和全部文件夹，按层缩进，共享给我的在后面一组，每行右边是复选框。勾了一个文件夹，它里面的文件夹也打勾、变淡，表示已经包括；勾根目录就是全部文件夹，不筛选，要只看某些文件夹先去掉它的勾。勾选立即生效，点外面或下拉关闭弹窗；一个都没勾就关掉时回到全部文件夹。
- 选中的文件夹删除了、退出了共享，就不再算在选择里，都没了时回到全部文件夹；它回来了（撤销删除、重新共享给我）又算在选择里。
- 筛选后没有可做的事项时，列表的位置写“这些文件夹里现在没有能做的事”，下面是主色文字的“看全部”，点了回到全部文件夹。
- 筛选时，快速添加的[目标文件夹](../ui.md#其他)默认是选中的第一个（按文件夹树从上往下），新加的事项不会一加就看不见；选过或固定了的照样用它，按钮上写着加到哪里。
- 选择按用户存在这台设备上，菜单栏小窗和主窗口共用一个选择。

## “接下来”里的后续

在“接下来”里就地看一项做完以后还有哪些事、哪一步另有前置，不用换到文件夹页或关系图。

- 按钮：有没结束的后续的行，右端是向下的箭头按钮（32，触摸区域 44），悬停提示“展开后续”；展开时箭头朝上、浅色底（secondary-container），悬停提示“收起后续”。展开和收起同[交互细节](../ui.md#交互细节)的展开动画。行的其他地方照旧：点勾选圈完成，点别处打开详情。
- 列出的事项：它后面没结束的事项，后续的后续也算，隔着已结束的不算（同[放弃](../design.md#放弃)时一起放弃的后续）。排法同[文件夹里](../design.md#排序)：后续紧跟在前置后面，一串排完再排下一项，同一层里按文件夹和手动顺序。
- 轨道从这一行的勾选圈接着往下画，画法同[轨道](../ui.md#轨道)：只画这些事项之间的连线，冗余的不画，从可做事项出发的线用主色；合并后超过列数上限时排成一列，只画这一行到第一项的线。节点是 14 的小圈：等待中的是轨道色虚线圈，可做的是主色圈（[重复](../design/repeat.md#重复)的事项这一次做过后，后续可能已经可做）。
- 每项一行，高 40：标题 14，等待中的用次要文字色；右边写一样次要信息（12），依次取第一个有的：
  - “完成后可做”（主色）：做完这一行马上能开始的，即行上“解锁 N 项”数的那几项；
  - “另需“收集数据””，几项时“另需 2 项”：这一串以外还有前置挡着它；
  - 还没到开始时间的，写开始时间，写法同[事项行](../ui.md#事项行)；
  - 截止时间，颜色同事项行；还没定下的写“前置完成后 3 天内”。
- 点一项打开它的详情，同点事项行；打开着详情的那一项用选中的底色。
- 超过 8 项时先列前 8 项，最后一行是主色文字“还有 5 项”，点了列全。
- 展开着哪些记在这台设备上，每个账号一份，默认都收着；这一项完成或放弃、离开“接下来”时一起收起，撤销后又展开。记录只留最近展开的 50 项，更早的撤销后是收着的。菜单栏小窗和桌面小组件的“接下来”也能展开，和主窗口共用这份记录。Android 小组件里没有：视图数有限，点开 App 就能看。
