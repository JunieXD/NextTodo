# 界面

视觉和交互的规格。定规格时用的可点击原型在正式前端做出来以后删掉了，要看可以在提交 `57a07ad` 里找。

这里写各处共用的样式、布局和交互；下面这些页面和功能另有详细的规格：[设置](ui/settings.md)、[改动记录](ui/history.md)、[隐私锁](ui/lock.md)、[日历](ui/calendar.md)、[“接下来”的筛选和后续](ui/next.md)、[关系图](ui/graph.md)、[弹窗、对话框、提示条](ui/dialogs.md)、[附件](ui/attachments.md)、[批量操作](ui/batch.md)、[拖动](ui/drag.md)、[共享](ui/sharing.md)。

## 设计方向

- **一处大胆，其余克制**：文件夹列表左侧的“轨道”是唯一的视觉重点，其他地方保持安静。
- **颜色有含义**：主色翡翠绿只表示“可做”；等待中用中性灰和虚线；逾期红，今天到期琥珀色。不用颜色做装饰。
- **Material 3 的配色和组件，iOS 的结构和手势**：Material 3 的颜色角色、导航指示条、筛选标签、悬浮按钮、对话框；iOS 的大标题、圆角分组列表、可拖动的底部面板、滑动操作。
- **动效只回应操作**：只在用户操作后出现，用来说明发生了什么变化；没有自动播放的装饰动画。

  - 浅色：primary 40，primary-container 90 / on 10，inverse-primary 80；secondary-container 90 / on 10；surface 98，surface-low 96，surface-container 94，surface-high 92，surface-highest 90，on-surface 10，inverse-surface 20 / on 95；on-surface-variant 30，outline 50，outline-variant 和 rail 80。group、seg-on 是白色。
  - 深色：primary 80 / on 20，primary-container 30 / on 90，inverse-primary 40；secondary-container 30 / on 90；surface 6，group 12，surface-low 10，surface-container 15.5，surface-high 19，surface-highest 24，seg-on 26.5，on-surface 90，inverse-surface 90 / on 20；on-surface-variant 80，outline 60，outline-variant 30，rail 40。

- 在设置的“外观”里选，一排 8 个圆点：7 种预设，最后是“自定义”（彩虹色的圆，选了自定义时是生成的主色），选中的带对勾，点了立即生效，和换主题一样整页淡入淡出。点“自定义”在下面展开调色，同[文件夹颜色](#文件夹的颜色和图标)的自定义，但没有饱和度和亮度的方块（不起作用），只有色相条和十六进制、R、G、B 输入框，边调边生效；从当前的主题色开始。色相落在红到黄之间（HCT 色相 10–100）时，下面一行小字“与逾期的红色、今天到期的琥珀色相近，可能难以区分”，不拦着。存在各自的设备上，自定义的存调出的颜色。
- 小组件、通知、提醒弹窗这些由系统绘制的部分不跟着变，仍用翡翠绿。

## 圆角、间距、阴影

- 圆角按层级区分：底部面板和对话框 28，快速添加栏 25（胶囊），其中的输入区 20，悬浮按钮 16，分组列表和关系图节点 14，分段控件 10（选中项 8），筛选标签和文件夹图标 8，描述里的清单框 5，事项勾选框为圆形。
- 左边对齐两条线：页面和弹窗的标题、正文、空列表的提示、输入框和分组列表对齐同一条边（手机、底部面板和弹窗里 16，电脑主区 28，菜单栏小窗的列表 12）；居中的确认框是一张小卡片，标题、正文和按钮在里面统一用 24。分组标题和分组下面的注释再缩进 16，和行里的文字对齐。表单页里另起的一组（如 AI 整理的“说明”）用输入框标题的样式，不用分组标题。普通行最小高 56，轨道列表行高固定 64。行左边的名称不压窄，右边的值（如设置首页的模型名、写入日历的文件夹）放不下时以省略号截断。
- 分隔线 0.5px，从文字起点开始，不贯穿图标。
- 左栏各项之间留 2 的间隙，选中项和悬停的相邻项不粘在一起。
- 阴影只用两级：分段控件选中项用一级，浮在内容上的元素（快速添加栏、悬浮按钮、提示条）用三级。

## 布局

| | 手机（窄于 1000px） | 电脑（1000px 及以上） |
|---|---|---|
| 结构 | 顶部栏 + 内容 + 底部栏 | 左栏 + 中栏 + 详情栏，左右两栏可以拖动调宽 |
| 导航 | 底部栏四项：接下来、[日历](ui/calendar.md)、文件夹、设置（图标是头像） | 左栏：接下来、已完成、日历、“文件夹”下的文件夹树、[“共享给我”](ui/sharing.md)、搜索；设置在左栏左下角（头像和名字），在中栏打开 |
| 收起 | | 中栏顶部左侧的按钮收起或展开左栏，带过渡 |
| 详情 | 底部面板 | 详情栏：默认收起，点事项时滑出，再点同一项或关闭按钮收回；详情开着时点别的事项直接换内容，不播动画 |
| 快速添加 | 浮在底部栏上方 | 中栏标题下方 |

- 电脑上左栏和详情栏的宽度可以拖动：指针移到它和中栏之间的分隔线上变成左右箭头，分隔线高亮，按住左右拖；双击分隔线恢复默认宽度。左栏 200–400（默认 272），详情栏 320–600（默认 400），中栏至少留 320，收着的那一栏不占地方：拖详情栏到中栏只剩 320 时停住，不挤左栏；拖左栏到中栏只剩 320 后，接着收窄详情栏，直到它的下限。放不下时（窗口变窄，或打开收着的一栏）先收窄详情栏，再收窄左栏，都不小于下限；地方又够了（窗口变宽，或收起另一栏）就回到选的宽度，所以收起一栏时，另一栏没被挤窄的不变，被挤窄过的回到选的宽度，其余让出的地方给中栏。宽度存在这台设备上，被挤窄的不算选过。
- 手机顶部栏高 44（加安全区），同 iOS 的导航栏，滚动前透明，向下滚过大标题后显示毛玻璃背景、分隔线和居中的小标题。
- 进入文件夹、从“接下来”进入“已完成”、进入[设置](ui/settings.md)的子页时，新页面从右侧滑入，返回时反向。电脑上换到左栏的另一处，或在列表和关系图之间切换时，中栏淡入（0.2 秒）。
- 文件夹树的顶层是根目录（图标与文件夹区分），展开是顶层的文件夹；计数是里面的待办数，含子文件夹里的，所以根目录的是全部的待办（别人共享给我的除外）。哪些文件夹收起着记在这台设备上，每个账号一份，重新打开、锁定再解锁后照旧；没收起过的都展开。“文件夹”小标题右边一个按钮：有展开着的文件夹时是“全部收起”，只留根目录下的第一层，“共享给我”里的也收起；都收着时是“全部展开”。树里没有子文件夹时不显示。不能新建和根目录同级的文件夹。别人共享给我的文件夹不在树里，在下面的“共享给我”一组，见[共享](ui/sharing.md)。
- 电脑上文件夹页的大标题上方写它在哪：“学习 / 毕业论文”，顶层的写“根目录”。每一段都能点，悬停变主色，点了进入那个文件夹。
- 手机“接下来”页的大标题右侧有“已完成”按钮（历史图标）。
- “接下来”按截止分的组，标题整行能点，右端一个小箭头，展开时朝下、收起时朝右；收起时标题后面写“5 项”，收起和展开同已完成区的折叠动画。见[接下来](design.md#接下来)。

### 返回

Android 的返回键（含侧滑返回）一次退一步：

1. 先关掉最后打开的东西：对话框、弹窗、展开的 AI 整理编辑页、文件夹菜单、关系图的连线状态、事项详情，再退出[批量操作](ui/batch.md)。
2. 都关了以后，在文件夹里回到上一级，在“已完成”回到“接下来”，在设置的子页回到设置首页。
3. 在底部栏的页面（“接下来”“日历”“文件夹”“设置”）之间切换不算一步，再按返回就退到后台。

网页的返回按地址的历史记录走，打开详情会加一条记录，所以返回也会先关掉详情。

### 同步状态

本机模式[借网盘同步](local/drive.md#立即同步)时，界面上一直写着上次同步是多久以前，点一下立即同步。连服务器时改动实时推送，只在本机时不同步，都没有这一项。

| | 手机 | 电脑 |
|---|---|---|
| 位置 | “接下来”大标题下面日期那行的下一行，小字，前面一个同步图标（14） | 左栏左下角头像那一行，名字下面的小字；这一行右端一个同步按钮（同“锁定”按钮），悬停提示“立即同步” |
| 立即同步 | 点这一行 | 点同步按钮；点这一行的其他地方照旧打开设置 |

- 平时写“刚刚同步”“3 分钟前同步”，还没同步过的写“尚未同步”，正在开启的写“正在开启同步…”。
- 点了以后同步图标转圈，写“正在同步…”，完了换回上次同步的时间；转圈时再点不起作用。
- 同步受阻时用 warn 色写“同步受阻：{原因}”，如“同步受阻：无法连接网盘”，放不下时省略；点了照样立即同步，就是重试。
- 同步自己停下了（如网盘里的文件夹换过）用 warn 色写“同步已停止”，没有同步按钮；手机上点了打开“借网盘同步”的对话框，那里写着原因，可以重新开启；电脑上点这一行打开设置。

### 文件夹的颜色和图标

[文件夹可以选颜色和图标](design.md#文件夹)：颜色是预设的或自己调的，图标是预设的。界面规格说“不用颜色做装饰”，这是用户自己选的例外，只用在文件夹的图标上。

- 预设的颜色 14 种，鲜明、彼此好分，靠颜色就能认出是哪个文件夹的事项：红 `red` `#f52027`、橙 `orange` `#fb7c05`、琥珀 `amber` `#f1a201`、黄 `yellow` `#e5d513`、草绿 `lime` `#96d507`、绿 `green` `#05b047`、青绿 `teal` `#0eb09e`、青 `cyan` `#03b5e4`、蓝 `blue` `#2071f3`、靛蓝 `indigo` `#5e44e6`、紫 `purple` `#a23de4`、粉 `pink` `#f43d99`、棕 `brown` `#8c5c3a`、灰 `gray` `#868686`。前 12 种的 OKLCH 色相依次约 27、52、74、104、128、148、182、225、260、282、308、355，亮度和色度取得鲜明。按下面的画法画出来，选颜色的圆点、两种主题页面上的图标，任意两种的 OKLab 色差都在 0.075 以上（最近的是浅色主题图标里的橙和琥珀、黄和草绿，约 0.08）。存的是名字。
- 自己调的颜色存成 `#rrggbb`。
- 预设的和自己调的画法一样，深色和浅色主题用同一个颜色。图标是这个颜色的线条图标，直接画在页面上，不垫底色方块；和页面的对比度在浅色主题里至少 2.2（对白色），深色主题里至少 3（对各主题色里最亮的 `--group-bg`，`#1b2122`）；不够的在线性光里往黑或往白混到刚好够，色相不变，所以白色在浅色主题里画成灰色，黑色在深色主题里也是。选中的行（secondary-container 底）上对比度低一些，黄色、靛蓝最低约 1.7：名字就在旁边，不为它把颜色压暗。没选颜色的用文字颜色。选颜色的圆点上，选中的对勾是白色，和这个颜色的对比度不到 2.2 时用深色（浅色主题的 `--on-surface`）。
- 图标 40 个（Lucide）：公文包、学士帽、书、笔、文档、笔记本电脑、代码、烧瓶、计算器、灯泡、靶心；房子、购物车、餐具、咖啡、衣服、婴儿、爪印、心、礼物；哑铃、自行车、心跳、药丸；钱包、存钱罐；飞机、汽车、地点；音乐、相机、调色板、游戏手柄；星、旗、火箭、奖杯、扳手、叶子、人群。没选图标的是文件夹图标（共享的文件夹是带两个人的文件夹），和现在一样。
- 本来有文件夹图标的地方换成选的：文件夹列表和选文件夹、筛选文件夹的弹窗（22，和事项的勾选圈对齐，文件夹名和事项标题从同一处开始）、电脑左栏的文件夹树（18）；根目录用自己的图标。本来没有图标的地方，选了颜色或图标才加上：文件夹页的大标题前面一个图标（24，手机 28），“接下来”和搜索结果里事项的文件夹路径、详情的“文件夹”一行前面一个小图标（14）。

### 轨道

文件夹列表按依赖顺序排列，左侧画类似 git 提交图的轨道：

- 勾选圆圈就是轨道上的节点；依赖沿轨道从前置所在行连到后续所在行，并行的支线分开成几列，列宽 24。
- 像地铁线路图那样合并线路：一个事项有几个后续时，共用一条轨道，到各个后续处分出去；几个只有这一个后续的事项指向同一项时，汇成一条轨道再接进去。常见的“一对多”“多对一”只占两列。合并有时会让分出去的线横穿别的轨道：两种合并都做、只做一种、都不做，四种排法里取交叉最少的，一样时取列数最少的。
- 合并后仍超过上限（手机 3 列、电脑 5 列）时，这个文件夹的列表不画连线，勾选圆圈排成一列，顶上一行“依赖较多，列表里不画连线”，点它切到关系图。
- 只画文件夹内、未完成事项之间的依赖，冗余的依赖不画（同关系图）。
- 从可做事项出发的线用主色（65% 不透明），其余用轨道色。
- 文字起点随轨道列数后移，分隔线跟着对齐。

### 底部面板（手机详情）

- 两档：半开（屏幕高的 60%）和全开。半开时不遮暗背景，可以继续点后面的列表或节点，详情跟着切换；全开时背景变暗。
- 从任何位置都能拖：内容滚到顶以后继续下拉，就是拖动面板；半开时上推会先展开到全开。快速下甩：全开降到半开，半开直接关闭。
- 半开时内容也能完整滚到底。
- 拖到关闭时，面板从松手的位置继续滑下去。

### 其他

- 控件都是自己做的，各端一样，不用浏览器自带的下拉框、日期时间框、复选框、校验气泡和悬停提示；只有选文件（恢复备份）用系统的窗口。
- 分段控件（iOS 样式）：列表和关系图切换、描述的预览和编辑切换、外观选择，以及只有两三个选项的设置（思考程度、重复的单位和下一次从哪天算）。
- 下拉选择：选项多的用它（提醒、重复、AI 服务商）。点开是和“…”菜单同样的列表，当前项右边打勾；在设置行上靠右对齐，在输入框样式的格子上靠左对齐。
- 菜单（“…”菜单、右键菜单、下拉选择）的大小跟着指针走：用手指时每项 44 高、15 号字，好点按；主要用鼠标或触控板时（`pointer: fine`）每项 32 高、14 号字、图标 16，和系统的菜单相近。
- 时间选择：顶上是输入框，可以直接输入几点几分，如“9:07”“9.07”“907”，只写几点的是整点（“9”就是 9:00）。手机上弹出数字键盘，用“.”分开时和分。边输入边生效（有的手机的数字键盘没有回车），回车收起；回车时输入不对，框变红。在下面两列里点选后，输入框清空。下面是时和分两列，分钟每 5 分钟一档，原来的和当前的时间不在档上时也列出；点开时两列滚到选中的位置。截止和开始的时间还没设时，点开就选上现在之后的下一个整 5 分钟（3:42 点开是 3:45，3:45 点开是 3:50；最晚 23:55），可以直接用，也可以再改；往后取，是免得设上就已经过了。开始和截止在同一天、另一个已经有时间的，选上的不早于开始、不晚于截止，这时可能不在整 5 分钟上（开始 23:58，截止就选上 23:58）。点小时后再点分钟，点了分钟就收起。底部是“不设时间”。
- 数字加减：两边是 − 和 +，到了上下限的那边不可点；中间的数字也能直接输入，超出范围的按上下限算。
- 输入建议：输入框下方弹出候选（如 AI 设置里从接口获取的模型），聚焦时列出全部，输入后按包含的文字筛选；可以用方向键和回车选。
- 复选框：圆角方框，和描述里的清单一样（如整理建议里勾选要采纳的修改）。
- 开关：开着是主色、圆点在右，关着是灰色、圆点在左；用于设置行上只有开和关两种状态的项（如登录时启动），行的说明只写用途，不写状态。
- 表单校验：提交时第一个空着的必填项边框变红，表单下方用红字写“请填写××”；服务端的校验错误同样标在对应的项上。
- 输入的文字：提交时去掉看不见的控制字符（有的聊天软件复制出来的文字里有，比如 Android 上的 QQ 用它们代替表情），换行和制表符除外；标题、名称这类单行的，制表符换成空格。
- 悬停提示：只有图标的按钮，用鼠标悬停约半秒后在旁边显示说明，反色小气泡（和提示条同色）；手指点按不显示。说明就是按钮的无障碍名称。
- 筛选标签（Material 3 样式）：显示已完成、包含子文件夹。
- 快速添加栏：有底色的输入区（和搜索框同色）和几个按钮：回形针（添加[附件](ui/attachments.md)）、✦（切换 AI 整理）、目标文件夹（只在“接下来”、[日历](ui/calendar.md)和 Android 的[快速添加小窗](android.md#快速添加小窗)里，名字过长时省略，见下一条）和发送。发送按钮两种模式都有，没有内容时不可用；切换模式时按钮不移动。按栏的宽度排：
  - 480 及以上（电脑、横屏的手机和平板）：一行，输入区在左，右边依次是回形针、✦、目标文件夹、发送；输入区变高时按钮留在底部。
  - 更窄（竖屏的手机、菜单栏小窗）：一行放不下，按钮会把输入区挤到只剩几个字。所以没在输入、也没有草稿和待添加的附件时，只有一条占满整行的输入区；点进去，或者有草稿、有附件时，展开成两层（圆角 22）：上面是整行的输入区（待添加的附件在它上面），下面一排按钮，左边回形针、✦，右边目标文件夹、发送。点下面的按钮（包括去拍照、选文件、选文件夹）不会收起；输入区空了、也没有附件，点按或焦点又到了页面里这一栏以外的地方，才收回一条（离开页面去选文件不算）。展开和收回 0.2 秒，高度和按钮的透明度一起变。
  - Android 的[快速添加小窗](android.md#快速添加小窗)不论多宽都是展开的两层：它弹出来就是为了记一条。
  - 输入区随内容增高，最多 5 行，再多就在框内滚动。占位文字只占一行，放不下时省略。回车添加事项，标题不能换行，粘贴的多行文字合成一行。“接下来”、日历和每个文件夹各有一份草稿：没提交的文字在切换页面、关掉再打开后仍在，提交后清空，退出登录时删除。
- 快速添加的目标文件夹：默认是上次选的，选了哪个记在这台设备上，各处共用，下次还是它。设置“列表和添加”里的[快速添加](ui/settings.md)可以改成固定一个文件夹：在栏里临时选了别的，发送一次后回到固定的那个；改回“上次选的”时从栏里现在显示的那个接着用。栏里用哪个，依次看：在栏里选的（固定时就是临时选的）、固定的、默认的，删了或退出了共享的跳过，回来了（撤销删除、重新共享）又用它。默认的是根目录，“接下来”筛选时是[筛选的第一个](ui/next.md#接下来的文件夹筛选)。
- 快速添加栏的 ✦ 按钮切到 [AI 整理](ai.md#添加)：✦ 按钮变为实心，用发送按钮提交，电脑上也可以用[发送键](ui/settings.md)：默认 Enter 换行、Ctrl + Enter（macOS 上 ⌘ + Enter）提交，可以改成 Enter 提交。设备记住上次用的模式；还没配置模型时，点 ✦ 打开设置里的“AI 整理”。
- 展开编辑：AI 整理的内容超过 3 行时，快速添加栏右上方出现展开按钮；两层时在下面一排的 ✦ 后面，不占输入区的宽度。手机上打开全屏的编辑页，电脑上打开居中的大窗口：标题“AI 整理”，右上角是收起按钮，下面是填满空间的输入区，左下角是回形针按钮，右下角是目标文件夹（只在“接下来”里）和发送按钮。编辑页和快速添加栏是同一份草稿，收起后文字留在栏里；发送后关闭编辑页。按键规则和栏里一样。
- AI 整理请求行：在所在文件夹的事项列表顶部，“接下来”顶部单独一组“AI 整理”（带文件夹路径）。左侧是状态图标（等待 ✦ 灰色、整理中转圈、失败为红色感叹号），标题是原文第一行（原文空着的见 [AI 整理](ai.md#附件)），下面一行是状态，失败时是红色的原因，右侧有“重试”。点开是原文和状态，失败的可以改原文后重试或按原文添加；右键菜单有重试、按原文添加、删除。
- 设置首页的“AI 整理”一行显示所用模型和保存位置，点开是模型配置，下面是[说明](ai.md#说明)。
- 描述里的清单是圆角方框，和事项的圆形勾选框区分开；可以直接点选。
- 描述里的单个换行，预览里也换行（同 GitHub 的评论）；空一行另起一段，代码块照原样显示。清单项的方框在第一行左边，换到下一行的文字和第一行对齐。
- 描述的编辑框下面紧贴一排按钮，只有图标（20），悬停提示写名称：左边是清单、列表、编号，最右边是撤销。用手指时按钮 44 高，用鼠标时 32 高，同菜单。编辑时这一排一直看得到：内容长、手机 App 里弹出键盘时，停在可见区域的底部（键盘上方）。点按钮不离开编辑框，键盘不收起，也不触发保存。
  - 清单、列表、编号：给光标所在的行（选了几行就是这几行，其中的空行不动）加上开头 `- [ ] `、`- `、`1. `；这些行已经都是这种时去掉；是另一种的换成这种，已经是这种的不变（清单的勾选照旧），编号从 1 依次重排。行首的缩进不变。
  - 撤销：撤销描述里的上一步，不碰标题等别处的输入（浏览器菜单里的撤销也一样）；打字按停顿和光标位置分步，输入法选一次字、按钮、回车接着写、插入附件引用各算一步。没有可撤销的时不可点；保存时换成了别处改的描述，从它重新算起。电脑上也可以按 ⌘Z（Ctrl + Z），⇧⌘Z（Ctrl + Y）重做。
- 描述的编辑框里，在清单、列表或编号的一行末尾回车，下一行自动带上同样的缩进和开头（编号加一，新的清单项不勾）；在只有开头的空项上回车，去掉开头，结束这个列表。认得的开头同预览：`- [ ]` 后面没写字时可以没有空格，编号后面也可以是清单。代码块里和输入法选字时的回车不算。
- 图标：24 网格、1.8 线宽、圆头圆角的线性图标。正式版用 Lucide，缺的自己按同样规格画。

## 产品图标

- 图形是一段清单：左边一条轨道串起三项，从上到下是已完成（实心圆点，对勾镂空）、可做（圆环）、等待中（虚线圆环），右边各有一条标题，画法和 App 里的事项状态一致。
- 底板是圆角方块，从左上 `#2E8E6C` 渐变到右下 `#14563F`。图形是白色；轨道、等待中的圆环和它的标题用 `#A6F2D1`；已完成的标题是半透明的白色。
- 单色的场合（macOS 菜单栏的模板图，Android 的通知小图标和主题图标）整个图形只用一种颜色，浅色部分降低不透明度。
- 图标文件都由 `apps/web/scripts/icons.js` 生成：网页的 `icon.svg`（也是浏览器标签页图标和左栏、登录页的品牌标）和各尺寸 PNG，Android 自适应图标的背景、前景、单色三层和通知小图标，iOS 的 1024 方形图标和启动画面的标志，macOS 的 `icon.icns`、各尺寸 PNG 和菜单栏图标，Windows 的 `icon.ico`（也是托盘图标）。改图形只改这个脚本，然后在 `apps/web` 下运行 `node scripts/icons.js`；脚本要用 `rsvg-convert`（librsvg）和 macOS 自带的 `iconutil`。

## 交互细节

- 完成一项：勾选框弹一下；这一项在原位多停留 0.9 秒，再用 0.3 秒收起，下面的行随之上移（文件夹里[保留](ui/settings.md)了最近完成的 N 项时，它划掉后留在原处，到时收起的是第 N+1 近完成的那一项，不到 N+1 项就都不收起）；收起期间轨道淡出，排好后按新的连线淡入；它解锁的事项闪一下 primary-container 底色（1.6 秒），提示条写“解锁了‘××’”，并附“撤销”。恢复成待办时提示条写“已恢复‘××’”，同样附“撤销”。重复的事项勾选框同样弹一下，但不划掉、不收起，截止时间随即换成下一次（“接下来”里这一行随之移到新的位置）；顺延到明天以后的，前面出现“今天已完成”；它[解锁](design/repeat.md#重复)的事项同样闪一下，提示条写“下一次：××”，有解锁的写“下一次：××，解锁了‘××’”，附“撤销”。结束重复并完成，和做完[重复到](design/repeat.md#重复)的最后一次，都和普通的完成一样划掉、收起；最后一次的提示条写“‘××’已完成最后一次”，有解锁的写“已完成最后一次，解锁了‘××’”，附“撤销”，让人知道它为什么没有顺延。
- 前置未完成或没到开始时间时勾选：先弹对话框确认，写明在等什么（“还有 2 项前置未完成”“要到 11 月 14 日 09:30 才开始”）。
- 列表行右滑超过 90px 完成，左滑超过 90px 删除，删除后可撤销。
- 文件夹里的事项和子文件夹可以拖动排序，也能拖进别的文件夹，见[拖动](ui/drag.md)。
- 右键菜单（电脑上用鼠标时，Mac 上按住 Control 点按也算右键；手指或触控笔的长按留给拖动，带触屏的电脑也一样）：事项有“打开”“在文件夹中显示”（只在“接下来”“已完成”、日历和搜索结果里有）“标为完成”“放弃”或“重新打开”“移动到…”“删除”，重复的事项在“标为完成”后面多“跳过这一次”（已是最后一次的没有）和“结束重复并完成”两项；文件夹（左栏和文件夹列表里）有“新建子文件夹”“AI 整理事项”“AI 说明”“共享…”（能共享的文件夹，见[共享](ui/sharing.md)）“重命名”“颜色和图标…”“复制…”“移动到…”“删除文件夹”（需确认），根目录只有“新建文件夹”“AI 整理事项”和“AI 说明”，别人共享给我的文件夹只有“新建子文件夹”“AI 整理事项”“AI 说明”“共享…”和“复制…”（退出共享在共享面板里）。文件夹页（根目录也是）标题旁的“…”菜单和它的右键菜单相同，只是“AI 整理事项”换成“…”前面单独的按钮（见[整理文件夹](ai.md#整理文件夹)），“AI 说明”后面多一项“批量操作”。其他地方右键没有菜单；输入框、选中的文字和链接保留浏览器自己的菜单，用来复制粘贴。
- 在文件夹中显示：右键菜单里的这一项，和详情里“文件夹”一行右端的按钮（向右上的箭头，悬停提示“在文件夹中显示”，占一指宽；点这一行的其他地方仍是“移动到…”；手机上详情下面就是这个文件夹时没有这个按钮）。打开事项所在的文件夹，列表还是关系图照这台设备的选择，正在搜索的结束搜索：列表滚到这一项、放在中间，闪一下（同解锁的闪烁），已完成的先展开底部的已完成区；关系图平移到这个节点，闪一下，已完成的而关系图没显示已完成的，打开显示已完成。电脑上中栏换成这个文件夹，详情栏不动（从这一项的详情点的，这一行是选中的），中栏本来就是这个文件夹的，只滚过去闪一下，不多一步返回；手机上详情收起，底部栏换到“文件夹”，返回时按文件夹页的规则回到上一级。文件夹加载得慢的，加载完再滚过去；要显示的事项这时已被移走或删除的，就不滚。别人共享给我的文件夹里的同样打开那个文件夹。
- 自己的 agent 批量改动后：提示条写“Claude Code 在‘求职’中添加了 4 项”，附“撤销”。别的成员的改动不弹提示条，只有两种和我有关的例外，见[共享](ui/sharing.md)。
- 鼠标指针：能点的元素都显示手型；关系图画布显示抓手，拖动时变成握拳；其他地方是默认箭头，文字上也是，只有能输入和能选中的文字上是 I 形。
- 文字选择：界面上的文字（标题、名称、事项行、按钮）不能选中，拖动、双击、右键、长按都不会选中。能选中复制的只有输入框、事项描述、改动记录里改前改后的值、令牌和错误详情。
- 不显示原生滚动条。
- 浮层（弹窗、对话框、底部面板、AI 输入页、提示条、菜单）进场时减速停下，关闭时沿原路加速离开，退场比进场短：手机上的面板约 0.26 秒，电脑上的卡片、对话框和提示条约 0.16 秒，菜单 0.12 秒。新的提示条直接盖在正在淡出的旧提示条上。
- 状态变化用过渡，不跳变：
  - 展开和收起（文件夹底部的“已完成”、电脑左栏的文件夹树）：0.25 秒展开、0.2 秒收起，高度和透明度一起变；打开页面时已经展开的直接显示。
  - 悬停、按下和选中的底色（列表行、左栏、菜单项、图标按钮、日期和时间）0.15 秒渐变，鼠标从一行移到另一行时，前一行淡出、后一行淡入。
  - 分段控件的选中块滑到新选的一项（0.25 秒）。
  - 批量操作：选择框缩放淡入，勾上和取消时渐变；不能选的行渐渐变淡（0.2 秒）。
  - Android 的[弹窗提醒](android/reminders.md#弹窗提醒)是原生界面，同样处理：换成推迟的选项、自定义时间或下一条提醒时，旧内容淡出、新内容淡入，卡片高度随之变化；完成时勾选圈和标题渐变；分段控件的颜色渐变。小组件由系统绘制，不做动画。
- 系统开启“减弱动态效果”时，去掉动画和过渡。
- 需要详细说明的地方附上[官网](https://juniexd.github.io/NextTodo/)教程的链接，在浏览器里打开（`ui/help.tsx`）：登录页的“了解两种用法”和服务器地址旁的“如何部署”，AI 整理设置的“如何获取 API 密钥”，本机模式卡片的“说明”，令牌生成后的命令行安装说明，设置“关于”里的“使用教程”。链接用主色加下划线，和正文分得清。

## 文案

- 简明书面：用“暂无、无法、失败、已、将、须”这类书面说法，句子尽量短；不用“没能、不对、马上、好了”这类口语，不对用户称“你”。界面、提示、错误信息、小组件、通知、命令行和工具输出都按这个风格。
- 不啰嗦，只写用户需要知道的：这一项是什么、有什么用、要注意什么。不解释怎么实现，不写看得出来的操作（拖哪里、点哪里）和当前状态，不罗列细节；能删的字都删掉。设置项的小字一句话说清用途，如“常驻桌面，位于其他窗口下方”，不写“摆在桌面上，在其他窗口下面，显示桌面时也在；拖顶上一行移动，拖边缘改大小”。
- 用用户能懂的话，不用系统内部的叫法；同一个操作从按钮到提示用同一个词（“撤销”→“已撤销”）。
- 空状态说明下一步能做什么，比如“暂无事项。可在下方输入，或让 agent 拆分计划。”
- 出错时说清发生了什么、怎么处理，不道歉，不含糊，比如“保存失败：{原因}”“无法连接服务器，请检查网络后重试”。
- 错误信息统一写成“{操作}失败：{原因}”；原因说不清时写“{操作}失败，请稍后重试”。可以重试的，统一说“请稍后重试”。
- 系统和第三方的原文（英文报错、错误码、`os error`、堆栈）不直接显示：原生部分和服务端先换成用户能懂的原因，比如“没有权限访问这个位置”“存储空间不足”，原文记进日志，网页的记进控制台。原生部分写好的中文提示已经说了是哪一步，原样显示；服务端返回的原因跟在“{操作}失败：”后面，表单里的错误紧挨着输入框，直接写原因。模型接口返回的错误例外：先说明状态码的含义，再在括号里附上原话，见 [AI 整理](ai.md#模型配置)。
- 页面崩溃时显示“页面出错”和“重新加载”，错误原文收在下面的“错误详情”里，供反馈问题时使用。
- 没有处理的错误出提示条“页面出错，操作可能未完成”，按钮“错误详情”打开错误原文，可以“复制”，见[网页端](web.md#出错)。
- 中文标点，中文与英文、数字之间留空格。
