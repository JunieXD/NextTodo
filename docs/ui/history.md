# 改动记录

设置里的一个子页，地址 `/settings/log`，内容见[改动记录和撤销](../design.md#改动记录和撤销)。

- 标题下面是“全部、已删除”的分段控件。
- 列表按天分组，组标题写“今天”“昨天”“11月20日 周五”（不是今年的加上年份）。每条一行写改了什么（只占一行，放不下时末尾省略），下面一行灰色小字写谁做的、几点和批次号，如“Claude Code · 14:32 · 批次 78”“本人（iPhone） · 09:05 · 批次 3”，放不下时省略来源的末尾，几点和批次号总是写全：撤销别的批次的写成“撤销批次 79：……”，按批次号就能对上是哪一条；右边是“撤销”文字按钮，已经撤销了的换成灰色的“已撤销”。点这一条的其他地方打开“改动详情”。
- 改动详情是弹窗。上面一组：“来源”（同列表里的写法）、“时间”（“11月22日 17:09”，不是今年的加上年份）、“批次”；撤销别的批次的，再多一行“撤销的批次”。下面标题是“改动”，这一批改的每样东西（事项、文件夹、依赖、附件、AI 整理请求、共享成员）一块，按改动的先后排：
  - 块的第一行写做了什么，同列表里的写法，但事项的标题写全，如“修改 #8 整理报销单”“移动、修改 #3 买菜”“删除文件夹 /旅行”“添加依赖 #3 买菜 → #5 做饭”。
  - 下面每个改了的字段一项：字段名一行（灰色小字），下面一行改前（灰色、划掉），再一行改后，没有值的写“无”。字段有标题、描述、所在文件夹、编号（移进移出别人共享的文件夹时换了）、开始、截止、提醒、重复、负责人、完成次数、名称、位置（文件夹在哪个文件夹里）、颜色、图标、所属（附件在哪个事项上）；在同一个文件夹里调整了顺序的，只写一行“调整了顺序”。完成一次重复的事项列出截止、开始和完成次数的变化。
  - 添加和删除的，列出它当时有值的字段，只写一行值（添加的是加上的，删除的是删掉、撤销能找回的），不划掉。
  - 描述的改前、改后各最多显示 4 行，超出的末尾有“展开”，点开看全文，再点“收起”。颜色和图标显示色块、图标和名字，自己调的颜色写 `#rrggbb`。完成、重新打开、AI 整理请求和共享成员的变化只有第一行。
  - 什么也没改的写“没有变化”。

  底部固定着“撤销”文字按钮，改动多时不随内容滚走，和列表里的按钮一样；撤销后弹窗不关，按钮换成灰色的“已撤销”。打开时向服务端取这一批（`log` 的 `batch`），取的时候写“正在读取…”，失败时写原因，附“重试”；这一批已不在记录里（超过 90 天）时写“这个批次已不在改动记录里”，不能撤销。
- 点“撤销”由服务端撤销那个批次（同 `undo`），所以很早的、别的设备上做的也能撤销；等回应时按钮不能点，成功后这一条变成“已撤销”，提示条写“已撤销”；那次改的东西已经不在或改回去了的（比如加的事项后来删掉了），提示条写“没有变化”，这一条不变；失败时写原因，比如批次里有无权查看的改动。
- 一次取 50 条，到底时有“加载更多”。改动同步过来时（包括刚撤销的）从头重新取，已经加载的几页一起取，看到的位置不变。都没有时写“90 天内暂无改动”（已删除里写“90 天内暂无删除”）。连不上服务器时写原因，附“重试”。
- 摘要和改动详情里的文件夹路径都按当时的名称和位置写，之后改名、移动、删除了也一样；查不到的（比如已经不再共享给我）写“已删除的文件夹”。中间有一段看不到的（比如被移出共享、后来又加回来），那段时间里的移动不知道，路径可能不全。
