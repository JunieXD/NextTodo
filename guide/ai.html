AI 整理 ​

把随手写下的一大段话交给 AI，整理成一条或几条事项：标题、描述、截止时间和先后关系都会填好，原文的信息不丢。也可以让 AI 整理一个文件夹里已有的事项。

NextTodo 不提供 AI，用的是自己在大模型服务商那里申请的 API 密钥，费用由服务商按用量收取。

1. 获取 API 密钥 ​

API 密钥是一串字符（通常以 sk- 开头），是在服务商那里使用模型的凭证，不要告诉别人。任选一家服务商：

服务商控制台说明
DeepSeekplatform.deepseek.com国内可直接使用
通义千问阿里云百炼国内可直接使用
OpenAIplatform.openai.com需要境外的支付方式

步骤大致相同：

  1. 注册并登录服务商的控制台，按要求完成实名认证或充值。
  2. 在控制台的“API Key”页面创建一个密钥。
  3. 立即复制并妥善保存：多数服务商只在创建时显示一次完整的密钥。

也可以用其他兼容 OpenAI 接口的服务商，选择“自定义”，填写它的接口地址和模型名称。

2. 在 NextTodo 里配置 ​

  1. 打开“设置 → AI 整理”，点“模型”。
  2. 选择服务商，接口地址和模型会自动填好。
  3. 把 API 密钥粘贴到“API 密钥”一栏。
  4. 点“测试”，显示成功就说明配置正确；失败时会显示服务商返回的原因，比如密钥错误或余额不足。
  5. 点“保存”。

在本机使用时，配置只保存在这台设备上，没有其他选项。连接服务器时，保存前还要选择“保存位置”：

保存位置密钥存在什么时候整理
仅本机这台设备上这台设备联网时
同步到服务器服务器上，加密保存提交后设备可以离线，服务器自己整理

选“同步到服务器”需要服务器设置过加密密钥，见部署服务器。

“思考程度”越高，整理得越仔细，也越慢、费用越高。

3. 把一段话整理成事项 ​

  1. 点添加框里的 ✦，切换到 AI 整理。
  2. 写下要做的事，想到什么写什么，可以很长。这时回车是换行。
  3. 点发送按钮提交；电脑上也可以按 Ctrl + Enter（macOS 上 ⌘ + Enter）。

提交后不用等：列表顶部出现一行“整理中”，整理好后变成事项，提示条写着添加了几项。不满意可以点“撤销”，原文还在，可以改了再试。

整理失败时，那一行会写明原因。点开它可以重试、修改原文后重试，或者“按原文添加”成一个事项。

发给服务商的内容：原文、提交时间、所在文件夹的路径，以及这个文件夹里未完成事项的编号、标题、截止时间和先后关系（最多 50 项），好让 AI 把新事项接在已有事项后面。已有事项的描述不发。

4. 整理已有的事项 ​

用自己的话告诉 AI 要对一个文件夹里的事项做什么：改标题和描述、补上或调整先后、改截止时间和重复、标为完成或重新打开、删除、移进子文件夹、新建、调整顺序，在界面上能做的都可以。AI 只提出建议，确认后才会修改。

  1. 点文件夹页顶部的“…”按钮（电脑上也可以右键文件夹），选“AI 整理事项”。
  2. 写下要求，比如“先订酒店再订机票”“把交报告推迟到下周五”“合并重复的事项”；或者直接用默认的“把标题改清楚，描述改成简洁的书面语，补上漏掉的先后关系。”。回车换行，电脑上按 Ctrl + Enter（Mac 上 ⌘ + Enter）提交。
  3. 整理好后，列表顶部显示“N 条建议，待确认”。点开它：
    • 每个事项先写着 AI 的理由，下面每处修改一个勾选框；新建的事项和调整顺序各自一组。
    • 取消勾选不想要的修改，点“应用 N 处”。应用后可以撤销。
    • 不想要这批建议，点“放弃”；想按现在的事项重来，点“重新整理”。

没写具体要求时，AI 只改写标题和描述、补上漏掉的先后；删除、完成、移动这类修改，要你在要求里说了才会提出。

整理时会把这个文件夹里未完成事项的标题、描述、截止时间、提醒、重复和先后关系，最近完成的 20 项的标题，以及子文件夹的路径发给服务商。
