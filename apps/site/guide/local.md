# 在本机使用

不部署服务器也能用：Android、macOS 和 Windows App 可以只在本机使用，不用注册账号，数据只存在这台设备上。

## 和连接服务器的区别

- **不同步**：每台设备的数据各自独立。要在多台设备之间同步，见[部署服务器](./server)。
- **没有网页版**：网页版只能连接服务器。
- **agent**：只能在电脑上接入，见[接入 agent](./agent#在本机使用时)。Android 上不能。
- **AI 整理**：配置只保存在这台设备上。
- **更新**：App 从 GitHub 获取新版本。

其余功能完全一样。

## 开始

第一次打开 App 时选“在本机使用”即可。已经登录了服务器的，先在“设置”最下方退出登录，再在登录页选“在本机使用”。

## 备份 {#backup}

数据只在这台设备上，设备丢了或坏了，数据也就没了。请定期备份，把备份文件存到别处，比如网盘或另一台电脑。

1. 打开“设置”，在最上面的“本机模式”一组点“备份”。
2. 选择保存的位置。备份文件名是 `NextTodo-备份-<日期>.db`。

备份里有全部事项、文件夹、改动记录和令牌，不含 AI 整理的配置和 API 密钥。

## 恢复

用备份替换这台设备上现在的全部数据：

1. 打开“设置”，在“本机模式”一组点“恢复”，选择备份文件。
2. 确认替换。App 会重新启动，打开后就是备份时的数据。

恢复前的数据不会删除，仍留在 App 的数据目录里。

换了新设备时，在新设备上选“在本机使用”，再恢复旧设备的备份，就能接着用。

App 无法启动时，页面上也有“恢复备份”按钮。

## 改用服务器

在“设置 → 本机模式”里点“改用服务器”，App 会重新启动，回到登录页。本机的数据保留在这台设备上，以后再选“在本机使用”可以接着用，但不会自动搬到服务器上。
